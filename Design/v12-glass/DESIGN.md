# 听页 · 琉璃（Liquid Glass）全盘重设计

- 方向：**原生液态玻璃（iOS 26 Liquid Glass）**
- 范围：视觉、信息架构、交互流程、功能取舍 全盘重想
- 最低系统：iOS 17（iOS 26 起用 `glassEffect`，旧系统用材质模糊兜底）
- 交付：本设计说明、`index.html` 设计稿、`render-app-icon-v12.swift` 图标、SwiftUI 源码实现

## 一、三条原则

1. **原生为骨，玻璃为肤。** 系统 TabView、导航栈、分档 sheet、Form 全部保留；iOS 26 起一切悬浮控件、卡片、按钮、导航坞改用 `glassEffect`（`regular` 与 `regular.interactive` 两档），旧系统退回 `regularMaterial` 材质模糊 + 发丝描边。玻璃只做「层」，不做拟物雕花。
2. **读听一体，一页到底。** 听书是阅读页的一种状态，不是另一个页面：朗读时正文底部浮出玻璃听条，正文原地高亮跟读；展开才是播放器。阅读与听书之间永远只有一层玻璃。
3. **澄蓝透光，宋体只在纸上。** 唯一强调色是澄蓝 `#0071E3`（深色 `#4DA3FF`），配合蓝 → 青 → 紫的极光渐变让色彩从玻璃背后透出来。界面一律系统字体；思源宋体只属于书名、正文与摘句（纸上的字）。

## 三、信息架构（重排）

**三页签 + 悬浮玻璃导航坞：**

- **书库**（原书架 + 原「今日」）：页头大字标题 + 玻璃圆形「＋」；续读卡在最前；搜索胶囊；书籍 / 漫画分段；分组、筛选、排序、网格 / 列表保留；整理模式不变。
- **足迹**（原足迹页签）：时长大数字、阅读目标、节奏图、逐次记录、按书排行、今日摘读。
- **设置**（原设置页签）：阅读偏好 / 听书声音 / 外观 / 数据与同步 / 隐私 / 关于，入口全保留。

**功能取舍与迁移：**

1. **「导入」页签并入书库。** 书库页头「＋」与空态按钮打开**导入面板**（sheet），本机文件、WiFi 传书、WebDAV、OPDS 全部收纳其中。导入是低频动作，不该常驻一个页签。
2. **页眉衬线改为系统大字标题。** 宋体不再用于界面 chrome，只保留给书名、正文、摘句与目录章节名。
3. **卡片去边框、去投影，改玻璃。** 浅色卡带 1px 白色高光边，深色卡带暗边；旧系统的兜底为材质模糊 + 发丝线。
4. **按钮全胶囊，主按钮为澄蓝玻璃填充。** 按压时玻璃轻微缩放与折射（`regular.interactive`）。
5. **设置小图标改为彩色渐变圆角方块**（iOS 26 系统设置风格）。
6. 保留：迷你播放器、隐私锁、隐藏书籍、iCloud 同步、实时活动与灵动岛（调色板同步澄蓝）、全部导入格式与听书服务商。

## 四、关键页面

- **阅读页**：正文仍是纸（七种纸色保留）；轻点唤出的顶栏、章节栏、听条、回朗读处胶囊、划线面板全部换成悬浮玻璃，浮在纸上、不改变正文尺寸。听条展开仍上滑进入播放器。
- **播放器**：整页以封面平均色渐变打底，玻璃层叠：封面卡、当前句卡、播放控制（大按钮为澄蓝玻璃圆钮）、底部玻璃工具条（章节 / 定时 / 语速 / AirPlay / 声音）。
- **锁屏实时活动 / 灵动岛**：深石底色 + 澄蓝进度与按钮（`TingyeWidgets/ListeningLiveActivity.swift` 同步）。
- **App 图标**：澄蓝 → 紫极光渐变底，白色玻璃书页与三道声波，页角高光（`Design/render-app-icon-v12.swift`）。

## 五、实现要点

- `Tingye/Theme.swift`：重写色彩令牌、玻璃组件（`glassSurface` / `glassCard`）、按钮样式、封面渐变；令牌名保持不变，全 App 自动换装。
- `Tingye/TingyeApp.swift`：页签改 3 个；导航坞玻璃化；导入页签移除。
- `Tingye/ShelfView.swift`：页头、续读英雄卡、导入面板入口。
- `Tingye/ReaderView.swift` / `PlayerView.swift` / `StatsView.swift` / `LibraryViews.swift`：面板与卡片玻璃化。
- `Tingye/Sources.swift`：WiFi 传书网页配色同步；`SourcesView` 作为导入面板使用。
- 版本：1.15.0（95）。
