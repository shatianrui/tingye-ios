# 听页 · 墨夜（Nocturne）全盘重设计

- 方向：**墨夜沉浸**——深色优先、以听为心，像音乐 App 一样对待一本书
- 范围：视觉、信息架构、交互流程全盘重想；数据格式、服务商连接、导入能力不变
- 最低系统：iOS 17（iOS 26 起悬浮控件用 `glassEffect`，旧系统退回材质模糊）
- 交付：本说明、`render-app-icon-v13.swift` 图标、SwiftUI 源码实现、模拟器走查截图 `previews/`

## 一、三条原则

1. **夜色为底，封面为光。** 默认外观为夜间（仍可在设置改为跟随系统 / 日间）。界面本身几乎没有颜色：墨黑底、炭灰卡片、暖白文字。颜色只来自两处——书的封面（取平均色铺成页顶的光晕）和唯一的强调色琥珀。
2. **正在听的那本书，永远在最前。** 新增「此刻」首页：页顶是当前这本书的封面光晕与大按钮；底部常驻的迷你播放器是一条带封面缩略图与进度线的胶囊；播放器像歌词页一样，把上一句 / 当前句 / 下一句排成一列，当前句最亮。
3. **纸只在阅读页。** 正文依旧是纸（七种纸色保留），其余一切是夜。宋体只属于书名、正文、摘句；界面一律系统字体，标题用粗大的系统字重。

## 二、色彩系统

| 令牌 | 日间 | 夜间（默认） | 用途 |

| bg | `#F5F3EF` | `#09090B` | 页底 |
| surface | `#FFFFFF` | `#151518` | 卡片 |
| surface2 | `#ECE9E4` | `#202025` | 次级底、次级按钮 |
| ink | `#141416` | `#F5F3EE` | 主文字 |
| ink2 | `#57534D` | `#ABA69E` | 次级文字 |
| ink3 | `#6E6A63` | `#85817A` | 弱化文字 |
| line | `#E2DED7` | `#26262C` | 发丝线 |
| accent 琥珀 | `#A65A00` | `#FFB547` | 唯一强调色：主按钮、选中、进度、朗读 |
| accentSoft | `#F7E6CC` | `#3A2A12` | 强调浅底 |
| onAccent | `#FFFFFF` | `#1A1206` | 强调色上的内容 |
| danger | `#C4302B` | `#FF8A80` | 破坏性操作 |

- 卡片：实色炭灰、20pt 连续圆角、无投影；夜间带 0.5pt 发丝亮边，日间带发丝暗边。玻璃只留给浮在内容上的东西（导航坞、迷你播放器、阅读工具栏、听条）。
- 按钮：主按钮琥珀实心胶囊、深色字；次按钮 surface2 实心胶囊、无描边。
- 朗读高亮：浅底 + 2pt 下划线，琥珀（浅纸用深琥珀，深纸用亮琥珀）。
- 锁屏实时活动 / 灵动岛：墨黑底 + 琥珀进度与按钮。

## 三、信息架构

**四页签 + 悬浮导航坞，迷你播放器常驻其上：**

| 页签 | 内容 |
| --- | --- |
| **此刻**（新） | 问候语与日期 → 封面光晕英雄区（正在听 / 上次读的书，大封面、继续听、阅读）→ 今日小结（今日分钟 / 目标环 / 连续天数，点按进入足迹）→ 最近在读（横滑封面墙，带进度）→ 今日一句 → 新入库（横滑） |
| **书库** | 大标题 + 琥珀「＋」导入 + 「整理」；搜索、书籍 / 漫画、筛选排序、网格 / 列表、分组全部保留。续读卡移到「此刻」 |
| **足迹** | 时长大数字、目标、图表、时段、排行（今日一句移到「此刻」） |
| **设置** | 分组不变；外观默认夜间 |

**取舍：**

1. 「继续阅读」英雄卡从书库移到新的「此刻」页，书库回归纯粹的「找书 / 整理」。
2. 书库根目录重新给出「整理」入口（上一版只在分组内可达）。
3. 迷你播放器改为音乐式胶囊：封面缩略图、书名 / 章节、播放 / 下一句、底边进度线。
4. 播放器当前句改为「歌词流」：上一句（暗）/ 当前句（亮、大）/ 下一句（暗），轻点上一句或下一句即跳句。
5. 今日一句从足迹移到此刻，避免重复。

## 四、关键页面

- **此刻**：顶部 420pt 的封面平均色光晕自上而下渐隐入墨黑底；英雄区内大封面带长投影，书名宋体 28pt，一行「第 n 章 · 已读 x%」，琥珀「继续听」与次级「阅读」。
- **播放器**：封面色光晕 → 墨黑的竖向渐变；大封面 220pt；歌词流；细进度条 + 句序号；大号白色圆钮播放；底部四个工具（章节 / 定时 / 语速 / AirPlay），选中时琥珀。
- **阅读页**：纸不变；顶栏、章节栏、听条全部是夜色玻璃浮在纸上。

## 五、实现要点

- `Theme.swift`：重写色彩令牌；`glassCard` 改为实色卡片（名字不变，全 App 自动换装）；新增 `nocturneBackground()`、`CoverGlow`；主 / 次按钮改实心胶囊。
- `TingyeApp.swift`：四页签、音乐式迷你播放器、导航坞；默认外观夜间。
- `NowView.swift`（新）：此刻页。
- `ShelfView.swift`：移除续读卡、根目录整理入口。
- `PlayerView.swift`：光晕底、歌词流。
- `ListeningLiveActivity.swift`：琥珀调色板。
