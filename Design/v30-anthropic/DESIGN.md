# 听页 · v30「Claude · Anthropic」设计文档

> 基线：`main` 分支，听页 1.25.0（构建 133 口径）。本文件是 v30 视觉的唯一文字事实来源；
> 令牌契约见 [`SWIFT-TOKENS.md`](SWIFT-TOKENS.md)，CSS 令牌见 [`colors_and_type.css`](colors_and_type.css)，
> 视觉原稿见 [`pages/`](pages/)，应用图标见 [`app-icon/`](app-icon/)。
> 信息架构沿用 v29「书房」：**阅读器即首页，书库为根页面/抽屉，「我的」经书库页工具栏进入**。本次只动视觉，不动 IA。

## 0. 主张与边界

- **主张**：把听页从「一个被设计过的阅读器」变成「一张安静的书页」。Anthropic 的视觉语言不是给界面加一层暖色，
  而是**减法**：让页面底永远是奶油画布，让白只用于卡片，让墨色分四档，让唯一品牌色只标记「正在发生」。
- **为什么是现在**：v29 已经把骨架换成「阅读器即首页」，v30 让这套骨架长出与其气质匹配的血肉。
  v29 §11 只做了三处「Anthropic 化气质调整」（圆角刻度、主按钮改深色、卡面柔影），配色一字未动；
  v30 是**第一次把整套 Anthropic 设计系统落到全界面**。
- **继承**：v29 书房的信息架构、阅读优先契约、读听位置分离、数据层不动、
  七纸族阅读纸色、单一导航与抽屉书库——全部不变。
- **硬边界**：不改数据层、不改导航结构、不改功能行为、不改文案语义、不改统计口径。
  阅读正文排版与用户已保存的字体、纸色偏好一律不动。

全部数值经 [`contrast-check.py`](contrast-check.py) 计算，脚本随设计稿入库，可随时复跑。

### 2.2 三条用色纪律

1. **页面底永远是奶油画布**，不出现纯白底。白只用于卡片与输入框——靠「白 vs 奶油」的对比分层，不靠阴影。
2. **陶土只标记「正在发生」**：当前章、在读印章点、进度已读段、跟读竖条、眉题编号。
   每屏至多 1–2 处。陶土**不做**按钮底、不做分段选中态、不做卡片底色。
3. **所有灰色都是暖中性**。系统冷灰（带蓝调）一律不出现。

### 2.3 两处刻意的偏离

| 偏离 | 原因 |
|---|---|
| `clayText` 日间取 `#A34E2B` 而非 Anthropic 官方的 `#C96442` | 官方陶土作小字对比度仅 3.9:1，达不到 4.5。本项目陶土承担「当前章标记、眉题编号」等小字语义，必须加深一档。 |
| `focus` 日间取 `#2D7FD8` 而非 `#3898EC` | 官方焦点蓝对奶油画布 2.90:1，低于 WCAG 2.2 焦点外观要求的 3:1。 |

其余色值与 Anthropic 官方品牌色完全一致。

## 3. 字体系统

Anthropic 的字体个性不在「有衬线」，而在**衬线只做展示标题、字重偏轻、界面层用无衬线**。中文没有可直接替代的
Anthropic Serif，本项目用思源宋体（`NotoSerifCJKsc-Regular`）承担同一角色，并坚持 **不做合成粗体**——
层级靠字号、留白与发丝线建立。

| 角色 | 字体 | 规格 | 用处 |
|---|---|---|---|
| 展示标题 | 宋体 Regular | 30pt / 20pt | 页标题、区块标题 |
| 书名与文学内容 | 宋体 Regular | 17–22pt | 书名、章题、摘句、今日一句 |
| 界面 | 系统字体 | 15pt，medium | 按钮、列表、设置、弹窗 |
| 眉题 | 系统 medium + 字距 1.6 | 11–12pt | 栏目眉题、编号 |
| 统计数字 | 等宽数字 semibold | 26–40pt | 时长、字数、目标进度 |
| 页码与时间戳 | 等宽 | 11–13pt | 序号、时间戳 |
| 正文 | 用户偏好五选一 | 默认 19pt | 阅读正文（**范围与偏好不变**） |

## 4. 形状、间距与阴影

### 4.1 圆角

| 令牌 | 值 | 用途 |
|---|---|---|
| `radiusSmall` | 8 | 小标签、书封 |
| `radiusField` | 10 | 输入框 |
| `buttonRadius` | 12 | 按钮 |
| `radius` | 16 | 卡片 |
| `heroRadius` | 24 | 大卡、升起面板、播放器头 |
| `radiusPill` | 9999 | 筛选块、分段控件 |

### 4.2 间距

4 基数：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48`；页面水平边距 24（375pt 小屏 20）；内容最大宽 720。

### 4.3 阴影

Anthropic 的抬升极浅，最深一档也只有 4% 黑。**层级优先靠发丝线与面差，其次才是阴影。**

| 场景 | 处理 |
|---|---|
| 静息卡面 | 黑 4%，半径 20，y 4（深色模式减半） |
| 浮层 / 升起面板 | 黑 8%，半径 16，y 4 |
| 列表行、底部面板、设置页 | **无阴影**，保持扁平 |

## 5. 动效

- 只保留两档：`pressSpring` 150ms、`smoothSpring` 200ms，均为 ease-out（对应 `cubic-bezier(0,0,0.2,1)`）。
- **删除回弹与位移**：主按钮的 Pow `pushDown` 下陷全部移除；`PressButtonStyle` 默认只做透明度 0.85，
  不再缩放。列表行、图标按钮不再有按压缩放。
- 「减少动态效果」仍是唯一闸门（`ReducedMotionPolicy`）。

## 6. 逐屏规格

以下为 v30 的**视觉**规格；功能与交互契约见 v29 文档第 2 节，不在此重复。

### 6.1 阅读器（首页）

- **静读态**：正文占满屏，无 chrome。页面底 = 阅读纸族，不受界面令牌影响。
- **工具态**：顶栏为返回 / 书名·章名（宋体 17pt）/ 书签 / 更多；底部四键「目录 排版 摘记 更多」，
  选中键下方一道 2pt 陶土短线（陶土纪律：这是全书最重要的那一处）。
- **听条**：`surfaceSubtle` 沉底，圆角 24，当前句宋体一行，左侧圆形墨色播放键，播放中旁一枚静态陶土点。

### 6.2 书库（抽屉 / 根页）

- 报头：眉题 `TINGYE · 书库`（陶土字）→ 2pt 墨线 → 宋体 30pt「书库」→ 计数行。
- 书目为**题录式列表**：封面 + 宋体书名 + 作者与进度小字，行间 0.5pt 发丝线，**无卡壳**。
- 在读行：书名左侧 6px 陶土印章点。读完行：书名后「读完」小字。
- 筛选胶囊：选中实心墨，未选中沉底 + 发丝线。

### 6.3 听书面板

- 封面 + 宋体书名章节；当前句大字（宋体 22pt）。
- 句子进度：轨道发丝线，已读段陶土。
- 播放键：64px 圆形墨钮（`Theme.ink` / `Theme.onInk`）；上一句 / 下一句为无底图标按钮。
- 工具四键「目录 语速 声音 定时」。

### 6.4 摘记

- 形态是**摘抄条**不是卡片：纸底，左侧 3pt 竖线（有笔记时陶土，无笔记时墨色），
  原文宋体 17pt，笔记系统字体 15pt，末行元信息（书名 · 章 · 日期，12pt `ink3`）。

### 6.5 专注会话与结束页

- 开始页只有三件事：时长、当前书名与章节、开始按钮。
- 进行中顶栏只显示剩余时间（等宽数字）与「结束」，无进度环、无跳动动画。
- 结束页：本次分钟大数字（等宽 40pt）+ 读到第 X 章 + 新增摘记数 + 今日一句卡。

### 6.6 读完收尾页

- 纵向三段：眉题（`读毕` / `全书读完`）→ 宋体书名大字 → 一行小结。
- 全书读完版另加「读完感」输入框、今日一句卡、下一本卡。

### 6.7 统计与阅读足迹

- 大数字一律等宽（`Theme.display`），柱状图已读段陶土、其余发丝线色。
- 目标达成用陶土点 + 文字双通道，不只靠颜色。

### 6.8 设置

- 单目录五组（阅读 / 听书与声音 / 书库与导入 / 数据与备份 / 通用）。
- 设置行：图标为墨色线性（陶土留给编号与眉题），行间发丝线，选中值 `ink3`。

### 6.9 添书与导入

- 来源卡（文件 / WiFi / WebDAV / OPDS / SMB）为白卡 + 发丝线 + 极淡柔影。
- 格式清单收敛为一处权威列表；导入结果逐项状态，已导入用墨色文字，失败用 `danger`。

### 6.10 空态与反馈

- 空态统一：宋体一句话 + 一个描边按钮，不出现插图型空态。
- 普通成功用可关闭的非阻断提示（墨底纸字细条）；破坏性操作仍需确认。

## 8. 深色模式

- 画布与卡面互换，**暖中性保持**：`#141413` / `#1F1E1D` / `#2A2926`；墨色梯度整体翻到纸端
  （`#FAF9F5` / `#EFEDE6` / `#98968E` / `#73726C`）。
- 陶土**不翻**：仍是 `#D97757`，但陶土字翻到 `#F0AD88`（深色上 9.69:1），淡底翻到 `#472E25`。
- 焦点环翻到 `#5AA9F0`。
- 阴影浓度减半（黑 2%），避免在炭黑纸面上发灰。
- 阅读纸族不变（用户偏好），界面层与正文层两套系统各自闭环。

## 9. 无障碍与适配

- 全部正文与关键文字 ≥4.5:1，由 `contrast-check.py` 守护；图标类 ≥3:1。
- 状态一律**双通道**：颜色 + 文字或形状（跟读 = 浅底 + 竖条；在读 = 印章点 + 小字；选中 = 浅底 + 竖条）。
- Dynamic Type 全量走字体阶梯；禁止固定字号 + `minimumScaleFactor` 缩字掩盖溢出。
- 主要图标操作命中区 ≥44pt。
- 「减少动态效果」下所有动效归零。
- SE 3（375pt）：边距 20，抽屉全屏，底栏四键等分。
