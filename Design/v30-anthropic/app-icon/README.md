# v30 应用图标 ·「声页 / Voice & Page」

Anthropic 语汇下的听页图标：奶油画布 + 炭黑墨的摊开书页 + 唯一陶土色的三道声波。

## 主张

- **一个品牌色**：陶土 `#D97757` 只出现在三道声波上，其余全部是暖中性。这是 Anthropic 的核心纪律
  —— 品牌色稀罕，所以它才有分量。
- **扁平**：无渐变、无描边、无高光。所有形体都是几何多边形与圆弧。
- **不抄标志**：Anthropic 的八芒星是其商标，本图标不使用。只借其配色纪律与排版气质。
- **书是主体，声是特征**：书页占下半，三道声波自书脊升起——「听页」二字。
- **48px 仍然可读**：三道弧等距（半径差 95px > 线宽 34px），互不粘连；小尺寸下先认出「三道波」，再认出「书」。

## 几何

| 元素 | 参数 |
|---|---|
| 画布 | 1024 × 1024 |
| 光学微调 | 整体上移 12px（书重弧轻，让视觉重心落在画布中心） |
| 书本 | 左页 `(176,496)→(504,576)→(504,814)→(176,736)`，右页镜像；顶边浅 V、底边浅 Λ |
| 书脊 | 两页中缝留 16px 地面色，垂直贯穿，不用楔形——楔形在 48px 下会糊成一个「T」 |
| 声波 | 圆心 `(512,630)`，半径 190 / 285 / 380，跨度 ±52°（对称于竖直轴），线宽 34，圆头 |
| 安全区 | 内容占画布约 62% 见方，系统圆角遮罩后仍完整 |

## 三变体

| 变体 | 底 | 书 | 声波 |

## 重新生成

```bash
cd Design/v30-anthropic/app-icon && python3 make-icon.py
```

依赖：`playwright`（Python）与 Chromium。渲染后必须复核 **1024×1024 / RGB / 无 alpha**——
iOS 资产校验会拒收带 alpha 的图标。
