## 0. 主张与边界

- **主张**：打开 App 即回到书里。阅读器是首页，其余一切（书库、摘记、统计、设置）都是阅读器的附属层。界面退后，纸面与正文向前。
- **为什么是这次**：v12–v28 约 28 个版本基本都在三页签信息架构上换皮（颜色、字体、图标、卡片），IA 从未动过。v29 第一次动 IA：取消底栏页签，启动直达阅读器，书库降为抽屉。
- **继承**：v16 墨（宣纸 / 墨 / 发丝线 / 宋体立骨）、v19 余白（大留白替代卡片与阴影、陶土只标记「正在发生」）、v20 刊（陶土块面、直角按钮、报头眉题）。三稿的共同契约——数据协议、读听位置分离、已保存的阅读偏好——全部不变。
- **硬边界**：数据层完全不动（见 5.3）；不做社交；不拆 AppModel；不改统计口径；不动导入引擎与无签名构建体系。

## 2. 逐屏规格

### 2.1 阅读首页（即阅读器）

- 正文占满屏，平时无 chrome；轻点中部唤出顶栏与底部菜单（开合不改变视口、分页与位置，现行 123 契约不变）。
- 听条：当前句 + 播放/暂停 + 进度细条，常驻在正文底部；点开**不跳独立页面**，在正文上方展开行内面板：句子流（当前句加粗大字、前 2 / 后 3 句可点即跳）、句子进度条、上一句 / 播放暂停 / 下一句、目录 / 语速 / 声音 / 定时、「回到原文」「结束听书」「回到朗读处」（常驻可见）。
- 锁屏与耳机线控行为不变（下一首 = 下一句的既有映射不变）。

### 2.2 书库抽屉

- 报头：眉题 `TINGYE · 书库` → 3pt 墨线 → 宋体 34pt「书库」→ 计数行。
- 列表为题录式：封面（4pt 圆角）+ 宋体书名 + 作者 / 进度小字，行间 0.5pt 发丝线，无卡片壳；网格模式保留但同样去壳。
- 在读行：书名左侧陶土印章点；读完行：书名后「读完」小字。整理多选态：整行浅底 + 左侧陶土竖条。
- 空态：宋体一句话 + 直角描边按钮「添加书籍」；0 本书时只显示搜索框与添书大按钮。

### 2.3 摘记页

- 形态是「摘抄条」不是卡片：纸底，左侧 3pt 竖线（有笔记时为陶土），原文宋体 17pt，笔记系统字体 15pt，末行元信息（书名 · 章 · 日期）。
- 顶部切换 本书 / 全部；按时间倒序；可搜原文与笔记；每条可回到原文 / 回到朗读处 / 复制 / 分享 / 删除；导出 Markdown 含章节与日期（补齐现缺口）；听条上可「为听到处加书签」。
- 空态：「长按正文，把喜欢的句子留在这里」。

### 2.4 专注会话与结束页

- 开始页只有三件事：时长（25 / 45 分钟，自定义 10–90 步进 5）、当前书名与章节、开始按钮。
- **计时搭现有 5 秒 tick 累计，不新建第二个时钟**（122「单一计时时钟」是已验证契约）；专注期间统计不双计，用对照用例证明。
- 进行中：正文不变，顶栏只剩剩余时间（每分钟更新一次文本）与「结束」；无进度环、无跳动动画。到时不打断阅读，只在页脚提示「专注完成 · 共读 X 分钟」。
- 结束页小结：本次分钟、读到第 X 章、新增摘记数、今日一句卡片（从本次划线取一条，无划线则取当日读到的一句）；主操作「继续读」「合上书」。

### 2.5 读完收尾页（合上书页）

- 纵向三段：眉题（`读毕` / `全书读完` / `专注完成`）→ 宋体书名大字 → 一行小结（本次时长大数字 + 本书进度 + 一句摘记回放）。
- 全书读完版另加：「读完感」输入框（一段话，存为本书笔记）、今日一句卡片（可换一句、可分享）、下一本卡片（待读第一本；无下一本则「去添书」）。
- 数字与足迹页同源同数，禁止在收尾页另算一套口径。

### 2.6 设置（单目录五组）

| 组 | 内容 |
|---|---|
| 阅读 | 排版默认值 / 纸色 / 翻页 / 简繁 / TXT 分章规则 / 选段菜单面板顺序（原「菜单」整页并入） |
| 听书与声音 | 声音提供方与 API Key / 语速 / 定时 / 跟读显示 |
| 书库与导入 | 导入格式说明 / 传书方式（WiFi / WebDAV / OPDS / SMB） |
| 数据与备份 | iCloud 快照 / 阅读进度同步 / 本地导出整库（新增）/ 空间整理 / 阅读足迹 |
| 通用 | 语言（明示「去系统设置切换」+ 跳转，不再是假入口）/ 启动行为 / 提醒 / 常亮 / 震动 / **回到旧版导航（过渡开关）** |

原 GeneralSettingsView、MenuSettingsView、ICloudBackupView、StorageView、Typography、TxtRulesView、VoiceSettingsView 全部挂进这一个目录；删除「我的页首齿轮 + 底部设置行」双入口；「我的书摘」不再挂在设置路由下。

### 2.7 导入页（添书）

- ImportHubView：从文件导入 / WiFi 传书（6 位口令）/ WebDAV / OPDS / SMB / 最近导入结果。
- 导入中逐项状态（等待 / 导入中 / 已导入 / 失败原因），单项失败不中断其余；无书源时书源区显示「还没有连过书源」，不隐藏入口。
- 一份权威格式清单（现行清单散在四处且不一致，本次收敛为一处）。

## 3. 功能取舍

| 类别 | 项 | 理由 |
|---|---|---|
| 新增 | 专注会话、读完收尾页、今日一句卡片、段落级摘记、本地导出整库、能力矩阵说明 | A 的核心仪式与补齐已知缺口 |
| 合并 | 三页签 → 阅读器 + 抽屉；三个播放器 → 一个（听条 + 行内面板）；划线/笔记/书签 → 摘记（呈现层）；设置双入口 → 单目录；导入 4 入口 → 1 个「添书」 | 消除重复入口与行为不一致 |
| 删除 | 底栏三页签与 `model.tab`、独立听书页（阶段三降为展开面板）、全局 MiniPlayer、此刻首页大数字卡、「我的」页 | 首页就是阅读器 |
| 保留 | 三种正文形态、CoreText 分页、排版、目录、书内搜索、导入格式与五种传书、iCloud 快照、进度同步、云语音、应用锁、统计记录、书库双模式与整理能力 | 阅读器本体与数据服务不动 |

**审计 10 条改进机会的表态**：① 读听位置——界面层合并（只呈现一个「当前位置」= 阅读位置，听书位置显示为「听到第 X 章」回落点；跟随朗读改显式开关「跟随中 / 已暂停跟随」；数据仍分开存；iCloud 仍只同步阅读位置，听书位置跨设备同步延后并在设置写明）；② 播放器统一——做；③ 摘记统一——呈现层做，删除独立（删划线不再连带删笔记，仅界面表达，底层记录关系不动）；④ 导入统一 + 本地备份——做，PDF base64 瘦身与快照历史管理延后；⑤ 设置重建——做；⑥ 全局搜索——延后（二期），A 期只做抽屉搜书 + 书内搜索；⑦ 统计口径统一——**不做**（单独立项），新页面与足迹页同源；⑧ 能力矩阵——做标注不补齐；⑨ 书库整理一等化——做（轻量）；⑩ 拆 AppModel——不做，只剥离导航状态。

## 4. 关键交互流程

- **首次启动无书**：书房空态 →「添一本书」→ 添书页；导入成功直接进阅读器第一页，不经过任何首页；失败在添书页逐项显示原因，可单项重试。
- **续读**：打开 App 直达上次在读书的阅读位置；上次在读书已删除 → 自动打开书库抽屉；上次只听了另一本 → 仍回到最近读过的书，听条显示正在听的那本。
- **切换书**：顶栏点书名或左边缘右滑 → 抽屉滑出，正文位置不丢；点另一本 → 抽屉关、直接开书；点抽屉外 → 回原书原位置。
- **划线摘记**：长按按句取段 → 选段面板（标注 / 笔记 / 引用）；可多选扩至整段；同章重叠且无笔记的旧划线自动合并（有笔记的不合并）。
- **听书跟读**：听条播放 → 逐句跟读高亮；手动翻页 → 跟随自动暂停并显示「已暂停跟随」，点「跟随」恢复；结束听书 → 听书位置保存，下次续听。
- **读完**：进度 100% → 收尾页 → 写读完感 / 分享今日一句 / 开始下一本。

## 5. 视觉系统

### 5.1 主张与动效基线

- 界面退后，纸面与正文向前。继承宣纸、墨、发丝线、宋体立骨、陶土只标记「正在发生」（每屏至多 1–2 处陶土）。
- **动效几乎为零**：全局只保留翻页（用户偏好决定，可关）与 0.2s 不透明度淡入淡出。删除现行 Pow 按压下陷（`pushDown`）与 `pressSpring / smoothSpring`；按压反馈只用透明度 0.85。「减少动态效果」从适配项变成默认状态，`ReducedMotionPolicy` 保留为唯一动效闸门。

### 5.3 字体裁决

**裁决：界面字体用系统字体（PingFang SC / SF），不用思源黑体。** 理由：① v15/v16/v19 三代设计稿与现行 Theme 注释都写「界面用系统字体」，是代码实现背离了契约，书房纠正实现；② 思源黑体只有 Regular，界面粗体全是合成字重，字形发虚；系统字体有真实字重；③ 系统字体天然跟随 Dynamic Type 并与 SF Symbols 基线对齐；④ 思源黑体约 16 MB 是字体包最大单项，界面解耦后其去留只由正文选项决定（见第 8 节未决 ①）。

| 角色 | 字体 |
|---|---|
| 界面（按钮、列表、设置、弹窗、眉题） | 系统字体；眉题 11–12pt medium 字距 +2；按钮 15pt semibold |
| 页标题、书名、章题、摘句、今日一句 | 思源宋体 `NotoSerifCJKsc-Regular`（仅 Regular） |
| 统计与收尾页大数字 | 系统字体 semibold + 等宽数字 |
| 阅读正文 | 用户偏好五选一不变（serif / kai / hansans / xixihei / system + 导入字体） |

**删除假粗体**：整体删除 `SerifEmbolden` 叠印修饰器与全部调用点，取消 `serifSemibold / serifBold` 的合成字重，`Theme.serif()` 只保留一个 Regular 入口；宋体层级靠字号 + 留白 + 发丝线建立，需要「重」的大标题用 34pt 宋体 Regular + 上方 3pt 墨线。将来确需真粗宋，唯一正道是引入思源宋体 Bold（约 +7 MB），须与无签名瘦身目标一并评估，不在本期。

### 5.5 圆角与间距

圆角从现行六种（8 / 10 / 16 / 24 / 胶囊 / 直角）收敛为三档 + 圆形：

| 令牌 | 值 | 用途 |
|---|---|---|
| `radiusNone` | 0 | 按钮、分段、筛选块、弹窗内行（默认形态） |
| `radiusSmall` | 4 | 书封、小标签 |
| `radiusSheet` | 8 | 抽屉顶角、底部升起面板、弹窗（唯一浮层圆角） |
| 圆形 | 50% | 播放 / 暂停键、印章点，仅此两类 |

- **阴影全局为零**：层级只靠纸色差与 0.5pt 发丝线；现行 `floatingPanel` 的 8% 黑阴影删除。
- 间距：页面水平边距 24（紧凑宽度 20）；内容最大宽 720 沿用；区块间距 24；组内行距 12；正文边距为用户偏好（默认 24），不进令牌。

### 5.6 组件规范（要点）

- **阅读器**：静读态只有正文 + 页脚小字（章名 · 本章进度 %，可关）；工具态顶栏 = 返回/抽屉 + 书名章名 + 书签，底栏四键直角无底色，选中键下方 2pt 陶土短线；听读态当前句 `claySoft` 铺底 + 左 3pt 陶土竖条（双通道，不只依赖颜色）。
- **按钮**：主按钮直角 `clay` 底高 50，整页至多一个；次按钮 1.5pt `ink` 描边；文字按钮 `clayText` 无下划线；图标按钮 44×44 命中区无底无描边，状态型图标用填充变体 + 陶土点，不整钮染色；分段/筛选块直角，选中 `ink` 实底（取代胶囊 `ChipPillStyle`），陶土不用在分段上。
- **面板**：排版 / 目录 / 摘记 / 设置为底部升起面板（`paperRaised`，顶角 8pt，顶部 2pt 墨线代替拖拽横条），分组以「2pt 墨线 + 宋体区块题」分隔，选项行命中区 ≥44pt。
- **听条**：高 56，`paperSunken` 底；左圆形播放键（`ink` 底），中部当前句宋体一行，右「展开」；播放中键旁一枚静态陶土小点（删除现行跳动声波 `symbolEffect`）。完整听书面板沿用此语言，播放键 64–68pt 圆形墨钮。
- **弹窗与提示**：确认弹窗用系统 alert / confirmationDialog 不自绘，破坏性按钮 `danger`；操作反馈用顶部细条（`ink` 底 + `paper` 字，直角贴边无阴影），停留规则沿用现行（普通 8 秒、VoiceOver 不自动消失）。
- **空态**：全 App 统一「宋体一句话 + 一个直角按钮」，不出现插图型空态。

### 5.7 深色模式：纸色从「色值」改为「纸族」

病灶：现行七种纸色除默认宣纸外全是写死浅色，深色 App 里仍用浅纸，被迫给控件与高亮打补丁；占位封色板只取浅色值，是第二套不咬合的系统。方案：每种纸定义日 / 夜一对值，选纸选的是纸族，呈现随外观：

| 纸族 | 日间纸 / 墨 | 深色纸 / 墨 |
|---|---|---|
| 宣纸（默认） | `#FAF9F5` / `#1C1B18` | `#141413` / `#EFEDE6`（与界面同值） |
| 雾灰 | `#E6EBF1` / `#14181F` | `#1D2733` / `#D8E2EC` |
| 旧书 | `#F3E7D6` / `#2C2418` | `#2A2118` / `#EAD9BE` |
| 浅灰 | `#F0F0F0` / `#242424` | `#1E1E1E` / `#E8E8E8` |
| 纯白 | `#FFFFFF` / `#14181F` | `#000000` / `#EFEFEA`（OLED 真黑） |
| 深蓝 | `#1A2C3A` / `#D5E4F0` | 同左 |
| 夜读 | `#101012` / `#EFEDE6` | 同左 |

- 每纸族自带 `secondary`（日 / 夜）与跟读带：跟读竖条统一陶土，铺底为陶土 14%（浅纸）/ 26%（深纸）透明度；现行钴蓝跟读带整体替换为陶土。
- 另设开关「浅纸常亮」（默认关）：开启后所有纸族锁定日间值，用显式偏好代替现在的隐性不一致。
- 占位封按纸族色板取日 / 夜对值，前景取对应 `ink`；真实书封不反色。
- 交界规则写死：听条、工具层永远用界面令牌；正文区永远用纸族值，两套系统各自闭环。

### 5.9 无障碍与适配

- Dynamic Type 全量走 5.4 阶梯；禁止固定字号 + `minimumScaleFactor` 缩字掩盖溢出。封面冻结字号定性为「封面是图像」，书名必须在相邻文本中以可缩放文本出现。
- 最大字号（AX5）：升起面板内容可滚动是硬规则；抽屉行改上下结构；双按钮行自动纵向排列；主按钮文字允许两行。
- SE 小屏（375pt）：边距 20，抽屉全屏，底栏四键等分，专注页大数字降一阶；矮窗口收尾页改横向滚动容器不压行高。
- 横屏 / iPad：最大宽 720 居中；宽屏双页分页沿用；抽屉在宽屏为定宽 360 侧栏；面板靠右下锚定。
- 对比度：正文与关键文字 ≥4.5:1 由自动化断言守护，扩展到全部新令牌与七纸族日 / 夜值；状态一律双通道（跟读 = 浅底 + 竖条、在读 = 印章点 + 小字、选中 = 浅底 + 竖条）。
- VoiceOver：图标按钮全量带标签；删除叠印后读屏重复朗读隐患消除；抽屉与面板出现时焦点移到标题。

## 7. 分阶段落地

## 8. 过渡与风险

- **老用户找不到书库**（全计划最大风险）：升级后首次打开阅读器，书名旁出现一次性提示「书库在这里，点书名或左滑打开」；抽屉把手带「书库」文字而非纯图标；设置 → 通用保留「回到旧版导航」开关，默认关，打开即恢复三页签与 MiniPlayer，数据完全互通；开关与旧视图代码保留至少两个版本周期后再议移除。
- **Mac Catalyst**：抽屉改左侧边栏（NavigationSplitView），不做底部 sheet；专注全屏改居中浮层。
- **小屏听条面板**：行内展开在小屏上改半高 sheet。
- **听书费用**：云语音按量付费不变；听条常驻后更易误触，首次展开面板时提示一次「云语音按用量计费，系统声音免费」。
- **数据层不动的范围**：Book/Chapter、ShelfEntry、ReadingProgress、Highlight、Bookmark、ReadingSession 模型；LibraryDisk 落盘与 catalog.json；ICloudArchive v1 与 BackupPacket v2 格式及恢复流程；ProgressSync；reader.*、goal.*、sync.progress 等偏好键。只动展示与导航层，新增导航状态为本地状态。

## 9. 明确不做

1. 不拆 AppModel（god object 与 run() 串行锁单独立项）；A 全部阶段只在其上做加法。
2. 不做社交（无共读、无动态、无账号、无服务器；金句卡片仅指系统分享导出）。
3. 不改统计口径（此刻纯阅读 vs 足迹含听书的不一致单独立项；唯一要求是新页面与足迹页同源同数）。
4. 不动数据层与备份格式，不做迁移脚本；摘记统一只到呈现层；若实施中发现必须动数据语义，立即停下另行评估。
5. 阶段一不做 Theme 令牌大扫除（只加必需令牌）；大扫除随视觉落地按 5.8 单独推进，不与导航改造叠加。
6. 不动无签名构建体系（脚本、空 entitlements、工作流）；无签名版 iCloud 失效文案属独立小修。
7. 不碰导入与传书内部（格式清单四处分散等问题只收敛清单本身；PDF base64、WebDAV/SMB 重复代码保留现状）。
8. 不补形态能力缺口（见第 6 节矩阵，只标注）。
9. 不改听书引擎与声音体系（SpeechPlayer、云语音提供方、声音设置草稿制不动，阶段三只收拢 UI 表面）。
