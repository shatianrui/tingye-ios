# v23「刊红 TIME」

参照《时代》周刊：红框封面、粗黑线分栏、宋体特粗标题。

## 色板（`Tingye/Theme.swift`）

| 令牌 | 日间 | 深色 | 用途 |
|---|---|---|---|
| accent | #D6001C | #FF6B6B | 红色文字：刊名、眉题、编号 |
| clay | #D6001C | #C8102E | 红色填充：主按钮、进度、页签指示、封面框 |
| ink | #111111 | #F2F2F2 | 正文与粗线 |
| ink2 | #5C5C5C | #A8A8A8 | 次要文字 |
| line | #DCDCDC | #333333 | 1pt 分隔 |
| surface2 | #F4F2EE | #1D1D1D | 摘句框等平底块 |

对比度：#D6001C 在白 5.42、在 #F4F2EE 4.85、在 #FBEDEC 4.75；#FF6B6B 在 #121212 6.75；白字在 #C8102E 5.88，均 ≥ 4.5:1。

## 规则

- 圆角全部为 0；圆形按钮、胶囊标签改为方形。
- 栏目头 3pt 墨线，条目间 1pt 细线。
- 封面统一套刊红框（`Theme.coverFrame`，宽度 × 5.5%）。
- 克制用红：选中芯片、设置图标、角带用墨色，红色只用于品牌元素。
- 阅读器按纸色切换红：深纸 #FF6B6B，浅纸 #D6001C。
