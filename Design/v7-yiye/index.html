一页：读与听，在同一页

「听页」的独特之处是边读边听。但现在读和听被拆成了三个地方：阅读全屏页、听书全屏页、迷你播放器，它们之间要来回跳转。界面也是自己画的（页签栏、工具栏都是自定义组件），和系统新的液态玻璃格格不入。这一版从结构上重做：听书变成阅读页的一种状态，不再是另一个页面；外壳全部改用原生组件；整套界面只用一种强调色。

问题 01读、听分家

阅读页底部三层工具栏 + 「听读模式」全屏页 + 迷你播放器。用户在读的时候点「听」，会被带离正文。

问题 02「发现」和「书斋」重复

「发现」只能推荐书架里已有的书（约定不做网络书城），内容和书斋高度重合，用户很难说清两个页签有什么区别。

问题 03自定义外壳与系统打架

自绘的悬浮页签栏、卡片阴影、按钮样式无法自动获得 iOS 26+ 的液态玻璃、动态字体和无障碍行为，每次换风格都要全部重画。

问题 04强调色规则太多

六轮改版下来叠了主色 + 金箔「只用于朗读」+ 朱砂「只用于 CTA」这样的规则，代码里留下大量兼容别名，文档和实际实现已经不一致。

三条原则

原生为骨外壳交给系统

系统 TabView、大标题导航、.toolbar、可分档 sheet、Form。iOS 26+ 自动获得液态玻璃，iOS 17–25 用同形状的材质模糊兜底。个性只放在书里：封面、衬线正文、朗读高亮。

读听一体听书是阅读页的一种状态

阅读页底部有一颗「听」键。点下后底栏变成「听条」，正文原地高亮跟读；上滑听条展开成完整播放器（sheet），下滑回到正文，始终是同一本书的同一页。

一色到底只有一种强调色：靛蓝

主按钮、选中态、进度、朗读高亮都用同一个靛蓝 #2F4C7D。没有「金箔只用于什么」「朱砂只用于什么」这类规则。封面保留自己的颜色，界面本身保持中性。

信息架构

页签仍是三个，但每个页签的职责更清楚了：「今日」负责今天要做什么，「书架」负责我有哪些书，「我」负责统计和设置。原「发现」的每一项功能都有新位置，详见文末的功能映射表。

少年闰土

这时候，我的脑里忽然闪出一幅神异的图画来：深蓝的天空中挂着一轮金黄的圆月，下面是海边的沙地，都种着一望无际的碧绿的西瓜，其间有一个十一二岁的少年，项带银圈，手捏一柄钢叉，向一匹猹尽力的刺去，那猹却将身一扭，反从他的胯下逃走了。

这少年便是闰土。我认识他时，也不过十多岁，离现在将有三十年了；那时我的父亲还在世，家景也好，我正是一个少爷。那一年，我家是一件大祭祀的值年。这祭祀，说是三十多年才能轮到一回，所以很郑重；正月里供祖像，供品很多，祭器很讲究，拜的人也很多，祭器也很要防偷去。

确认后的实施计划

  1. 令牌重写：Theme.swift 收敛为 12 个语义色，加上间距、圆角和玻璃修饰器 .glassSurface()（iOS 26 用 glassEffect，旧系统用 .regularMaterial）。删除兼容别名，逐个修复调用点。
  2. 外壳原生化：TingyeApp.swift 换成系统 TabView（今日 / 书架 / 我）和底部附件形式的迷你播放器；保留现有 alert、busy 浮条和 -uireview 走查入口，并补上新场景 today。
  3. 今日 / 书架：新建 TodayView.swift（吸收 DiscoverView 的逻辑）；在 ShelfView 加入分类筛选和列表视图；DiscoverView 删除。
  4. 一页：ReaderView 的 bottomPanel 拆成「玻璃工具栏」和「听条」两个组件；听条上滑展开 PlayerView（重新设计，背景取封面色）。分页、高亮绘制、跟随逻辑不改。
  5. 面板：字样、目录、声音、iCloud、详情、我，逐页换装成原生 Form / sheet 分档。
  6. 图标与小组件：新增 render-app-icon-v7.swift，生成明 / 暗 / 着色三套图标；Live Activity 调色板同步换成靛蓝。
  7. 验证：先跑完 44 项单元测试；再用模拟器 -uireview 逐屏截图，对照本稿检查明暗两套；最后更新 README 的「设计」一节。按约定，版本号等你确认 UI 后再改。
