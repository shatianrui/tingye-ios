## 一、原则

1. **像一份每天出刊的杂志。** 纸白底、墨黑字，用粗墨线而不是卡片阴影分栏；每个区块有「01 / 02 / 03」编号；首页刊头写期号（一年中的第几天）与日期。
2. **每本书一块纯色。** 无封面图的书是番茄 / 克莱因蓝 / 柠檬 / 薄荷 / 紫 / 墨六种纯色色块：细线眉题「听页 · 文库」、宋体粗书名、作者。没有渐变、没有玻璃、没有投影。
3. **三种颜色，各管一件事。** 墨（结构、主按钮、进度）；信号红（每屏一个重点：继续听、「＋」、选中下划线）；荧光黄（正在朗读的句子与摘句，像荧光笔划过）。

字体：页标题 / 刊头 = 系统黑体（Figma 以 Noto Sans SC Black 示意）；大数字 = 系统黑体压缩字宽 `Theme.display`（Figma 以 Barlow Condensed Black 示意）；眉题 = 11pt 粗体加字距 `Theme.kicker`；书名、正文、摘句 = 思源宋体。

## 三、信息架构

四页签：**今日 / 书架 / 足迹 / 设置**。底栏是纸底实色、顶部 1.5pt 墨线，选中项墨色粗体 + 信号红短横；迷你播放器是一条墨色实底条（夜间反白），底边荧光黄进度线。

- 今日：刊头 → 01 封面故事（色块封面 + 宋体书名 + 88pt 进度大数字 + 信号红「继续听」）→ 02 今日（今日分钟 / 目标百分比 / 连续天数三栏大数字）→ 03 最近在读 → 04 今日一句（荧光笔摘句）→ 05 还没开卷
- 书架：「书架」+ 整理（墨线方钮）+「＋」（信号红方钮）→ 3pt 刊头线 → 描边搜索框 → 下划线分段「书籍 / 漫画」+ 排序 → 色块封面网格（书名 + 进度眉题 + 详情）；列表模式为发丝线分隔的书目行
- 书籍详情：封面色块刊头（作者 · 分类 · 格式眉题、52pt 宋体书名、墨线、已读 / 篇幅 / 读到三个大数字）→ 01 简介 → 02 目录与书摘 → 管理
- 阅读：纸不变；顶栏、章节栏、听条都是与纸同色的实底 + 1.5pt 墨线框；朗读高亮为荧光笔底 + 墨色下划线（深纸为暗黄底）；操作强调色为信号红
- 播放器：上半封面色块刊头（小封面 + 40pt 宋体书名），下半纸上的句子流，当前句荧光笔划出；1.5pt 墨线下是「03 ━━━ 12」句序号、墨色圆角方钮与章节 / 定时 / 语速 / AirPlay
- 足迹：3pt 刊头线 → 下划线分段 → 压缩体大时长 + 阅读 / 听书图例 → 01 阅读节奏（墨柱，今天信号红）→ 02 每日目标 → 03 逐次记录 → 04 排行（大号编号）→ 05 阅读足迹
- 设置：编号区块（01 阅读偏好 … 06 关于听页），单色线性图标 + 发丝线分隔，不再使用彩色方块

外观默认「跟随系统」（上一版墨夜默认夜间）。

## 四、App 图标

柠檬黄底、墨黑粗体「听」、右下一个信号红方点（像句号，也像正在播放的指示灯），顶部一道墨线呼应刊头分隔线。夜间版墨底黄字，着色版灰阶。图标 PNG 直接从 Figma `04 App 图标` 导出（`icon-light.png` / `icon-dark.png` / `icon-tinted.png`），已去除透明通道后放入 `AppIcon.appiconset`。
