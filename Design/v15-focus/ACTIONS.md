# 功能键分层 · 专注版交互更新

本次是 **v15「极简·专注」的功能键布局更新**，不是新的视觉方案。保留浅灰紫、系统字体、四页签、阅读纸色及用户已保存的排版偏好。用户追加要求完成后推送 TestFlight，因此递增为 **1.18.0（106）**，已于 2026-10-20 完成 iOS 与 Mac Catalyst 上传；Apple 回执为正在处理，尚未确认可安装。未提交正式 App Store 审核。

[查看本轮实际运行截图](action-previews/index.html)。

## 组织原则

- **导航、内容定位、播放、配置分开。** 按钮名说明动作；打开面板不等于开始播放。
- **常用操作固定位置。** 播放状态改变时不增删整排工具、不挤动其他入口。
- **低频操作集中收纳。** 书架排序只排序，阅读更多只放阅读设置，听书声音统一管理声音与输出设备。
- **按内容适配，不缩小文字。** 图标操作至少 44pt；大字号改为两列 / 换行，低高度的工具可滚动。

## 状态与行为契约

1. **阅读翻章不控制声音。** 箭头、滑杆、目录都只改阅读位置并退出跟读；通过「回到朗读处」显式恢复跟读。听书目录才改变朗读章节。
2. **播放按钮与展开按钮互不替代。** 初次点阅读「听书」会从阅读位置开听并进入听书页；已有会话时同位置显示「听书页」，只展开，不恢复暂停。书架中当前听书书籍的「打开播放器」同样不恢复播放。
3. **暂停不改变正在浏览的位置。** 恢复播放才回到朗读处。迷你播放器只有展开和播放两种动作；结束听书在完整播放器内二次确认，进度保留。
4. **拖动松手提交，辅助功能直接调整即时提交。** 阅读滑杆会丢弃拖动期间章节已变化的旧目标；听书滑杆继续保留换书 / 跨章保护，暂停定位不自动播放。
5. **定时状态可见。** 当前剩余分钟按真实截止时间刷新；关闭后恢复「定时」，无障碍值为「未开启」。估算朗读剩余时间仍标记「约」，不伪装音频时长。
6. **整理与浏览隔离。** 未选择时批量操作不可用；删除仍二次确认。隐藏书籍的验证入口从排序移到「更多」，反馈文字同步更新。搜索时暂时收起页首和书籍 / 漫画切换栏，为小屏键盘上方的结果让出空间；取消后恢复完整浏览入口。
7. **显示偏好不被覆盖。** 大字号使用列表并说明原因，回到普通字号恢复原网格 / 列表偏好。

## 自适应与测试入口

- 阅读工具区保持浮层，不因显隐重新分页。大字号用两列；内容高于可用区域时独立滚动，返回按钮留在顶部。
- 听书大字号 / 低高度窗口只固定播放与跳句，其他内容可滚动；四个工具保持同一顺序。
- 书架浏览工具空间不足自动换行，整理按钮文字不截成一行。
- 自动化继续使用 Debug `-ui-fixture`，临时书库、系统声音、关闭 iCloud；新增 `-ui-reset-preferences` 仅在此模式下给纸色和书架布局设可修改初值。不能用 `-reader.paper` / `-shelf.layout` 锁定启动参数后再测试切换。
- UI 回归在 `TingyeUITests/DesignFlowTests.swift`，涵盖原有 9 项和新增 7 项：固定四键 / 读听定位分离、日夜菜单、书架分层 / 删除取消、声音 / 定时、迷你播放器 / 结束确认、最大字号阅读、横屏播放。
- 最终构建 106 验证：iPhone 17e 102 / 102（86 核心 + 16 UI）、iPhone SE 3 16 / 16 UI；两端 Release 归档与包检查通过。完整证据见 [验收记录](../../docs/ACCEPTANCE.md)。模拟器结果不能代替真机 VoiceOver、蓝牙 / AirPlay、来电、付费云语音和跨设备 iCloud 验收。
