## 视觉原则

1. **界面退后，书与文字向前。** 不再使用报刊式粗黑线、装饰编号、压缩黑体大数字、整块高饱和封面刊头。
2. **浅灰紫、低饱和、少边框。** 通过留白、字体层级与必要的 0.5pt 分隔线组织信息；不为每个内容区套卡片。表单与悬浮工具允许柔和表面。
3. **系统字体承载界面。** 页标题 26pt、书名通常 title2 / title3，正文说明使用语义字号。用户已保存的阅读字体、字号和纸色不被强制重置；新安装的正文默认系统字体，仍可选思源宋体、文楷和导入字体。
4. **真实书封优先。** 完整展示导入书封；没有书封时使用低饱和、简洁排字的纸本占位，不伪造真实版本封面。
5. **主操作深、辅助操作轻。** 主按钮为深灰紫胶囊，次按钮为浅灰紫；首页常用方式为文字主按钮，另一种方式为带完整无障碍名称的圆形图标。辅助功能字号下恢复双文字按钮、纵向排列。

## 页面落地

- **今日**：品牌与搜索 → 无框续读区 → 最近在读列表（最多三本）→ 真实七日阅读记录 → 待读清单。搜索切换到现有书架搜索，不维护第二份查询状态。今日一句保留在足迹，不再挤占首页。
- **书架**：去掉刊头线与搜索粗框；整理有文字、添加为浅紫圆按钮、筛选用轻量胶囊。新用户默认列表，已有网格 / 列表选择保持；辅助功能字号强制列表。
- **书籍详情**：独立书封、完整书名与小字号信息，不再放大封面平均色、用大字展示百分比。
- **播放器**：保持紧凑书名栏与正文跟读，改系统字体、灰紫色高亮、圆形播放键、细分隔线。进度仍明确为句子，不伪装成音频时间。
- **阅读页**：默认浅灰紫 / 柔和夜色；工具栏去粗边框，轻微投影分层；边读边听的播放按钮为圆形。PDF、原书图文、分页与用户排版偏好继续有效。
- **足迹 / 设置**：取消装饰编号和海报数字，同步系统字体、轻量区块与外观预览。
- **底栏 / 迷你播放器**：去掉选中红横线、粗黑分隔和整块墨底；保留四个独立导航栈及原有控制入口。

## 不能回退的交互

- 每本书的主操作遵循实际读 / 听记录；正在播放可直接暂停。
- 句子滑杆松手跳转，暂停不自动恢复；换书 / 跨章时不应用旧拖动目标。
- 剩余时间必须标“约”；成功反馈不弹确认；混合导入逐项保留结果。
- 图标交互范围 >= 44pt，关键文字支持 Dynamic Type；长句、小屏、最大字号需要回归。
- 最大字号 / 矮窗口播放器仅固定播放与跳句，其余区域可滚动。
- VoiceOver 的标签、选中态与减少动态效果适配继续保留。
