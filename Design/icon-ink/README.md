# 听页图标 · 墨 Ink（线装书题签）

v16「墨 · Ink」界面定稿后同步重设计的应用图标，取代 1.18.0（105）的「抱书的小王子」。

- **概念**：界面占位封的品牌化——一册线装书：宣纸底、左侧书脊与订线、竖排宋体题签「听页」、题签下一方朱砂闲章。全图标只用令牌色：宣纸 `#FAF7EF` 系、墨 `#1C1B18`、朱砂 `#A63A2E`。
- **三变体**：默认（日间）/ 夜间（墨黑底、深纸书册、浅朱砂 `#D97B6C` 印）/ 着色（灰度底，实际色调由 iOS 施加）。与界面日夜令牌一致。
- **源文件**：`ink-book.svg`（1024 viewBox，唯一源）；`render-icons.py` 负责暗色 / 灰度调色板替换、Chrome 无头渲染与 PNG 校验（1024×1024、不透明、无 alpha），`--install` 才写入 `Tingye/Resources/Assets.xcassets/AppIcon.appiconset`。
- **预览**：[index.html](index.html)（三变体与 60/80/120 小尺寸）；渲染记录与 SHA256 在 `build/ink-icon/`。

小尺寸识别要点：书册轮廓、书脊竖条、题签白签与朱砂点四者在 60pt 仍可分辨；题签文字为宋体 600 字重。
