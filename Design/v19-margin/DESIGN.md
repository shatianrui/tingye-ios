## 视觉方向

暖纸与石墨形成安静、清晰的阅读空间。陶橙只标记正在发生的动作，杏色强调继续阅读。以大留白和细分隔线替代蓝色大块、漂浮阴影及重复卡片。界面采用系统字体；书名、阅读引句使用项目已包含的思源宋体。

## 构图契约

### 读 / Now
- 顶部小眉题 `TINGYE / READ & LISTEN`，大标题「给自己，一页安静。」；搜索始终可达。
- 续读是暖沙色的书签式主卡片，不是饱和品牌色背景。左侧书名 / 作者 / 进度，右侧较大的真实封面。顶端状态胶囊；底部石墨主阅读按钮 + 线框/浅表面听书按钮。读听主次仍由 resumeActions 决定。
- 最近在读以清晰封面列表呈现，首屏能看到区块标题；阅读习惯是轻量七日点阵，不是第二个主视觉。

### 书 / Shelf
- 标题「书架」+ 动态本地数量；添加为醒目操作，整理为次要操作。
- 书籍/漫画使用短分段；筛选/排序/显示保留独立按钮。搜索时继续收起非必要头部。
- 列表放大封面至约52，行标题 serif，进度为小数字 + 极细线；网格是书封 + 书名，不给每本加厚卡壳。
- 详情采用暖纸色标题区域和居中/并排书封，阅读/听书双操作明确。

### 听书 / Player
- 上部轻量收起 / 看原文 / 更多，保留封面入口。小封面与书名信息在暖沙表面上形成“唱片标签”，不做巨大唱片占据长句空间。
- 正在朗读的句子为宋体与陶橙短竖线、温暖高亮；上下句安静但可读。
- 底部控制台使用无重阴影的内容表面；64~68圆形石墨播放按钮，左右44pt跳句，目录/语速/声音/定时固定顺序。
- 最大字号与矮窗口的可达性、暂停定位、真实句子进度完全保留。

### 阅读 / Reader
- 正文纸色、字体等偏好不重置。新的工具栏用细分隔和中性表面，四键目录/排版/听书/更多有明确的选中与按压状态。
- 目录、搜索、书签、摘记、排版弹层沿用统一的标题、分组、选项胶囊、最小点击区。

### 己 / Profile
- 标题「阅读足迹」；本周期分钟数是视觉主角；周期分段、阅读/听书时间和图表有层级。
- 目标卡为暖杏条状；今日摘句使用衬线留白。
- 设置是分组题录：阅读、声音、传书与备份、隐私和关于。入口不删减，不虚构账号/会员。

### 初版图标 / 折页声窗（109 历史）
石墨底 + 一张暖白折角书页 + 陶橙播放声窗。无文字，无渐变光晕，无额外圆角遮罩（交由系统）。Figma 矢量为源，导出 1024px PNG 后转换无 alpha，保留源 SVG 与导出证据。

**110 已替换为 GPT Image A「纸间回声」**：暖纸底、石墨书脊、陶橙翻页；默认资源使用生成原图，深色 / 着色从同一位图作色彩适配。新图标是栅格资产，不是上述矢量母版。详见 [新图标说明](../icon-margin-gpt/README.md)，本文件其余 UI 规范不变。
