# 听页 · 方向 A「书房 · The Study」设计说明

状态：高保真方向稿（v16 · a-study）。配套自包含预览：[index.html](index.html)（390×800 机框 × 9 屏，中文标注）。本方向是 v15「专注」之后的全盘重设计候选，**不改动任何功能与 Swift 代码**，只重组织视觉与信息架构。

## 方向定位

日间优先的温暖纸质书房。安静、踏实、有木质书桌与绿植的感觉——像走进一间采光好的书房，而不是打开一份报刊或一块玻璃。它刻意不同于 v12 的冷玻璃与 v15 的灰紫极简：用暖纸色、宋体书字、立着带书脊阴影的书封，营造「书是实体、界面是家具」的气氛。

## 三条设计原则

1. **纸的温度。** 页底用米白暖纸，分隔只用发丝线，不用粗框与强对比色块；书名、正文、摘句一律宋体，界面 chrome 退后。
2. **书的实体感。** 书封带 2–4pt 书脊阴影与右侧落影，像立在桌上的真书；首页当前书以「斜倚」姿态呈现，是唯一有姿态的元素，其余一律端正。
3. **克制的点缀。** 进度只用墨绿细线；赭石只出现在印章、星级、目标达成等「值得盖章」的时刻；主操作永远是墨绿实心胶囊，全 App 只有一种主按钮。

- 正文与关键文字对比度 ≥ 4.5:1（日间墨绿 #2F5D46 对米白约 6.8:1，次级文字对页底约 5.4:1；夜间反向成立）。
- 主按钮文字：日间白字于墨绿（约 6.8:1）；夜间深底字于浅绿（约 8.9:1）。
- 赭石不用于长正文与小号关键文字，仅作图形化点缀（印章描边、星形、短标签），其承载的语义同时以文字复述（如「达成 ★」「已达成」），不单独依赖颜色。

## 字体与间距

- 界面一律系统字体；页标题 28pt Bold，分组标签 11–12.5pt 加字距大写感处理。
- 书名 / 阅读正文 / 摘句用思源宋体（`'Noto Serif SC', 'Songti SC', serif`）：书架与详情书名 15–22pt，阅读正文默认 18–19pt、行距约 2.0。
- 页面水平边距 18–24pt；卡片内边距 14–20pt；卡片间距 12–16pt；行级信息一律发丝线分隔。
- 用户已保存的阅读字体、字号、纸色不被本方向重置；新安装默认纸色改为「米白暖纸」。

## 圆角与阴影规范

- 卡片圆角 16–20pt 连续圆角；搜索框 / 分段控件 12–14pt；主按钮与胶囊为半圆（高度一半）。
- 卡片阴影极轻且偏暖：日间 `0 1px 2px rgba(64,58,40,.05) + 0 10px 28px rgba(64,58,40,.07)`；夜间改为低透明度黑影。禁止大面积深色投影。
- 书封形态：右侧圆角 8–9pt、书脊侧 2–3pt；左缘 2–4pt 深色渐变模拟书脊阴影，外加 3–5px 侧向落影，日夜不反转（书是实体）。
- 播放主键圆形实心墨绿；上一句 / 下一句为次级表面圆形；迷你播放器的播放键与展开键是两颗独立按钮。

## 信息架构

```
┌─ 书房（首页，原「今日」改组）
│   问候 + 日期（小字）
│   桌上在读：当前书斜倚大卡（封面 / 章节 / 细进度线 / 继续阅读 · 听书）
│   最近在听：横向小卡（封面 / 章节 / 剩余约 X 分钟）
│   今日阅读时长条（目标达成时盖赭石印章）
│   待读清单（小封面 + 宋体书名 + 发丝线）
├─ 书架
│   搜索 → 书籍 / 漫画分段 → 网格⇄列表切换
│   筛选 / 排序 / 整理（轻量胶囊）
│   网格：三列立式书封 + 书名 + 状态小字
│   列表：封面缩略 + 宋体书名 + 细进度线 + 百分比，发丝线分隔
│   隐藏书籍入口退到页脚小字
│   └─ 书籍详情：立式书封 / 宋体书名 / 格式·字数·进度 /
│      剩余约 X / 继续阅读 + 开始听书 / 简介 / 目录摘要 / 书签·划线·统计·导出
├─ 足迹
│   日 / 周 / 月 / 年分段；今日总时长（读 + 听拆分）
│   每日目标细线进度（达成盖赭石印章、连续天数斜戳）
│   本周节奏柱状图（墨绿柱 + 次级表面未来日）
│   今日摘读：宋体卡片，可「从这句继续读」
└─ 设置
    阅读（排版与七种纸色 / 字体管理 / 书架与整理）
    听书与外观（声音与朗读 / 外观模式）
    数据与同步（iCloud 备份与阅读位置同步 / 导入与传书 / 导出阅读数据）
    关于
```

微调说明：页签数量不变（四个），「今日」更名「书房」并承担首页职能——原今日页的续读、待读保留，新增「最近在听」与「今日时长条」，今日摘读仍留在足迹页，避免首页拥挤。书架、足迹、设置的功能项与 v15 一一对应，仅视觉换新。阅读器与播放器不进出页签，保持既有导航栈。

## 关键交互契约（沿用 v15，不得回退）

- **读听定位分离**：每本书的主操作遵循实际读 / 听记录；阅读位置与听书位置各自保存，互不覆盖；正在播放时主操作可直接暂停。
- **播放键与展开键不互替**：迷你播放器与底部听条上，播放 / 暂停是实心圆键，展开播放器是独立的箭头键，两者各自 ≥ 44pt 且不互相变成对方。
- **滑杆松手提交**：句子 / 章节滑杆拖动只预览，松手才跳转；暂停不自动恢复；换书、跨章时不应用旧的拖动目标。
- **剩余时间一律标「约」**：如「本章剩余约 6 分钟」「剩余约 3 小时 20 分钟」，不给伪精确值。
- **触控与字号**：全部可点区域 ≥ 44pt；关键文字支持 Dynamic Type；最大字号下书架强制列表、首页恢复双文字按钮纵排、播放器仅固定播放与跳句（其余可滚动）。
- **反馈**：成功操作不弹确认；混合导入逐项保留结果；长句、小屏、最大字号布局需回归。
- **可访问性**：VoiceOver 标签、选中态与减少动态效果适配继续保留；本稿中「达成 ★」「已达成」等赭石语义均有文字复述。
- 进度以句子表述（如「第 12 / 86 句」），不伪装成音频时间戳。

## 与 v15「专注」的差异

1. **气质从冷到暖**：灰紫冷底（#FAF9FD / #756184）整体换成暖纸 + 墨绿 + 赭石（#F6F2E9 / #2F5D46 / #B07D4F）；夜间从灰紫夜换成暖黑绿（#161913）。强调色从「紫」换成「书房墨绿」，点缀色（赭石）是全新角色，且被严格限制在印章语义。
2. **信息从列表到场景**：首页由「今日」列表式堆叠改为「书房」场景式布局——桌上在读斜倚大卡是唯一主角，最近在听、时长条、待读依次退后；书封全部加上书脊阴影与落影，第一次让书在界面上「立起来」。
3. **宋体角色扩大**：v15 只在正文用宋体，本方向把宋体延伸到书名、摘句、章节题与设置图标字戳，形成「书用宋体、家具用系统字」的双层秩序；同时卡片化回归（16–20pt 暖影卡片），替代 v15 的无框分区，以承载「书房家具」的块面感——但发丝线、细进度线、低对比的克制规范全部保留。
