# 听页 · 墨 Ink（方向 B）

状态：v16 全盘重设计方向稿，高保真 HTML 见同目录 `index.html`（自包含、无外部依赖，9 个 390×800 界面）。本文件为视觉与信息架构规范说明；功能范围与 v15「专注」完全一致，只重组外观与导航。尚未进入 SwiftUI 实现。

## 方向定位

现代东方书卷。把「听页」从一款玻璃质感工具，转译为一册排版精良的现代线装书：宣纸为底、墨色为文、朱砂为印。气质是克制与留白——像书目题录，而不是报刊；避免粗黑线框、装饰编号、海报式大字与整块高饱和封面刊头。朱砂是全局唯一的彩色强调，出现次数被严格预算。

## 三条设计原则

1. **纸墨为体。** 页底为宣纸色，文字为墨色，强调只用朱砂。全界面每屏至多出现一到两处红：当前句下划线、印章点、主按钮、选中态，四者不同时抢戏。
2. **留白分区。** 几乎无卡片。信息分区依赖呼吸感与 0.5pt 发丝线；表面色（白 / 次级米灰）只给搜索框、听条、题签封面等真正需要抬升的元素。
3. **宋体立骨。** 书名、页标题、摘句、Tab 小字用宋体，允许竖排装饰（书架页右侧竖排「书架」小印、阅读页页脚竖排章名）；界面正文与控件一律系统字体，保证可读性与 Dynamic Type。

使用约束：

- **朱砂预算**：仅用于当前句高亮下划线、印章点（小方块 / 小圆点）、主按钮与选中态。不做大面积铺底，不用作普通链接色之外的装饰。
- **金** 仅用于「精排 / 精装」标识的描边（标识内文字仍用墨色，因 `#9B7B4A` 对宣纸仅 3.7:1，不承载文字），日间夜间同值，不参与其他语义。
- **对比度**：正文与关键文字配色 ≥ 4.5:1。已核验（WCAG 相对亮度计算）：日间墨 `#1C1B18` 对宣纸 `#FAF7EF` = 16.1:1；次级 `#6B6759` 对宣纸 = 5.3:1；朱砂 `#A63A2E` 对宣纸 = 6.0:1；朱砂浅底上的纸色文字（印章钮）= 6.0:1；夜间主文字 `#EFEDE6` 对 `#101012` = 16.2:1；夜间次级 `#A5A296` 对 `#101012` = 7.4:1；夜间朱砂 `#D97B6C` 对 `#101012` = 6.3:1。夜间发丝线 `#2C2C33` 仅作分隔，不承载文字。
- 无封面占位（题签封）随日夜切换纸色与墨色；导入的真实书封不反色。

## 字体与间距

- **宋体**（`'Noto Serif SC','Songti SC',serif`）：页标题 34pt 600、书名 17–23pt、摘句与阅读正文（默认 17pt / 行距 2.15）、章节题 21pt 居中加宽字距、Tab 小字 11pt。
- **系统字体**：界面正文 13–15pt、说明与元信息 10.5–12.5pt、按钮 14–15pt（字距 +2）。
- **间距**：页面水平边距 26pt；阅读页边距加宽至 38pt；题录行高 15–16pt 内边距；区块之间 20–22pt 或以发丝线分隔。
- **圆角**：主按钮 12pt；搜索框 / 题录表面 10pt；印章方 5–6pt；封面 3pt（书册感）；播放键为圆形。
- **发丝线**：分隔一律 0.5pt，不用 1pt 以上实线。

## 信息架构

四页签并为三页签，单字命名，Tab 图标配宋体小字：

```
书 ──┬─ 书架（题录列表 / 网格，书籍 / 漫画）
     ├─ 搜索（沿用书架同一份查询状态，结果分「书架 / 笔记与划线」）
     ├─ 添加（文件 / WiFi 传书 / WebDAV / OPDS 面板）
     └─ 筛选 · 排序 · 整理 · 隐藏书籍
读 ──┬─ 今日续读续听（主操作按实际读 / 听记录）
     ├─ 七日读听记录
     └─ 待读清单
     （阅读页 / 听书播放器为独立场景，不进 Tab）
己 ──┬─ 统计（日 / 周 / 月 / 年，阅读目标）
     ├─ 今日摘句（从这句读 / 听这本书）
     └─ 设置：外观与纸色 · 阅读排版 · 声音与朗读 · 传书与导入 · 备份与同步
```

调整理由：v15 的「今日」与「足迹」本质都是"读"的时间线，合并后首页只做一件事——回到书里；「设置」降为「己」页下半的题录清单，不再占独立页签。原四页签的独立导航栈与全部入口保留，仅是归位。

## 关键交互契约（沿用 v15，不能回退）

- **读听定位分离**：阅读位置与听书句位各自保存，互不覆盖；每本书主操作遵循实际读 / 听记录，正在播放可直接暂停。
- **播放键与展开键不互替**：阅读页底部听条、迷你播放器的"展开"（上箭头）与"播放 / 暂停"是两个独立控件，职责不合并。
- **滑杆松手提交**：句子 / 进度滑杆松手才跳转，暂停不自动恢复；换书 / 跨章时不应用旧拖动目标。
- **剩余时间必标「约」**（如"余下约 12 分钟"）；进度表述为句子（第 34 / 96 句），不伪装成音频时间。
- **44pt 触控**：全部图标可点区域 ≥ 44pt（本稿图标按钮一律 44×44）。
- **Dynamic Type**：关键文字支持动态字号；辅助功能字号下首页双按钮恢复纵向排列，书架强制列表，最大字号 / 矮窗口播放器仅固定播放与跳句，其余可滚动。
- 成功反馈不弹确认；混合导入逐项保留结果；VoiceOver 标签、选中态与减少动态效果适配继续保留。

## 与 v15「专注」的差异

1. **气质转向**：v15 是浅灰紫的"退后"，本方向是宣纸 / 墨 / 朱砂的"书卷"。强调色从灰紫 `#756184` 换为朱砂 `#A63A2E`，且使用预算更严（当前句、印章点、主按钮、选中态之外不用）。
2. **宋体前置**：v15 里宋体"只在纸上"，本方向让宋体承担页标题、书名、Tab 小字与统计数字，界面骨架本身即有书卷气；正文与控件仍系统字体，可读性不让步。
3. **页签四并三**：「书 / 读 / 己」取代「今日 / 书架 / 足迹 / 设置」；今日与足迹合并为「读」，设置并入「己」。功能入口零删减。
4. **选中与进度语言**：底色选中块改为朱砂小圆点 / 小方点；进度条改为 0.5–2pt 发丝线（当前段朱砂）；播放器当前句由浅底高亮改为朱砂下划线。
5. **封面语言**：无封面占位从低饱和色块改为线装书题签（朱砂浅底书脊 + 竖排题签 + 小印），日夜随纸色切换；真实导入书封照旧完整展示、不反色。
