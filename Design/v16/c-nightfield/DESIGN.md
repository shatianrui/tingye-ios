# 听页 · 星野 Night Field（方向 C）

深色优先的沉浸媒体感重设计：把阅读 App 做出音乐 / 播客 App 的质感。**夜空为底，封面是唯一的光源。** 功能全集与 v15 完全一致（四页签功能、书架管理、阅读器、听书、统计、导入、iCloud 同步一项不少），视觉与信息架构重新组织为三页签「此刻 / 书库 / 我的」。

预览：`index.html`（自包含单文件，390×800 机框 × 9 屏，中文标注）。

---

## 一、方向定位

| | 说明 |
| --- | --- |
| 气质 | 深夜听播客 / 看专辑封面的沉浸感。界面退场为夜空，书封发光。 |
| 默认模式 | **夜间为默认**，日间为同等完整度的浅色变体，而非反色附属品。 |
| 与 v13 的差异 | v13 是单色琥珀 + 炭灰的克制编辑感；本方向用**极光青→紫渐变**与**封面取色光晕**，氛围更浓烈、更未来。 |
| 与 v15 的差异 | v15 是浅灰紫、低饱和、界面退后的"纸张感"；本方向是深色媒体感：玻璃悬浮控件、大封面英雄区、迷你播放器常驻。交互契约不变（见第六节）。 |

## 二、三条设计原则

1. **夜空为底，封面发光。** 页底纯黑 `#060608`；首页与播放器用当前封面取色生成大面积径向光晕，封面是界面里唯一的高饱和光源。无封面书用深灰渐变 + 排字占位，不伪造封面。
2. **极光只给关键时刻。** 青→紫渐变严格限定于：进度线、选中态（Tab / 芯片 / 目标环）、主按钮、当前句竖条。其余界面保持低饱和灰阶——氛围浓烈但不喧哗。
3. **悬浮玻璃，发丝亮边。** 控件一律半透明 + 背景模糊 + 顶部 1px 发丝高光；大圆角 20–24pt；播放键 64pt 极光圆；迷你播放器是常驻 Tab 上方的悬浮玻璃胶囊。

## 五、信息架构

四页签 → 三页签，迁移理由：**「正在读 + 正在听」是同一个"此刻"**，拆成今日/书架两页会让进厅路径多一跳；统计与设置同属"关于我"，合并减少一个低频次页签。

```
此刻 (NOW)                书库 (LIBRARY)              我的 (ME)
├─ 英雄区：当前书          ├─ 搜索                     ├─ 统计：日/周/月/年
│   大封面+取色光晕        ├─ 筛选芯片(在读/漫画/未读/  │   读青听紫双色拆分
│   续读 / 继续听 双主按钮  │   已隐藏) + 排序 + 整理    ├─ 每日目标环 · 连续天数
├─ 「继续」队列            ├─ 网格 / 列表双视图          ├─ 阅读排版 · 声音 · 外观
│   (读与听各就各位)        │   封面下极光进度线          ├─ iCloud 备份与同步
└─ 今日时长环              ├─ 书籍详情                  └─ 导入与导出
                            │   读/听双轨进度(分离)         (WiFi/WebDAV/OPDS)
                            └─ 目录/书签/划线笔记
─────────────────────────────────────────────────────────
迷你播放器：后台播放时常驻于 Tab 上方（封面缩略图 + 渐变进度线
+ 独立展开键与播放键），全屏播放器与阅读页内不重复出现。
```

- 「此刻」问候语随时段变化（早上好 / 晚上好），英雄区永远展示"最该继续的那一本"：正在播放 > 最近在听 > 最近在读。
- 书库保留 v15 全部能力：书籍/漫画分段、网格/列表、筛选/排序/整理/搜索/隐藏书籍、四种导入入口。
- 足迹功能并入「我的」统计区（日/周/月/年 + 目标 + 连续天数），"今日摘读"保留在统计页下方（本稿 9 屏未展开，落地时置于目标环之后）。

## 六、封面取色与光晕生成规则

1. **取色**：从封面图提取主色（大面积色）与点缀色（高饱和小面积色，如《小王子》的金星）。
2. **光晕**（首页英雄区 / 书籍详情 / 播放器背景）：两个径向渐变叠加——主色 alpha .16–.30 置中上，点缀色 alpha .12–.26 偏移一侧；高斯模糊 16–18pt；背后再铺一层封面主色相的深色调大径向渐变（alpha ≤ .55，从顶部 46–55% 高度渐隐到纯黑页底）。
3. **光晕不改页底令牌**：渐变末端必须完全透明，页面底部区域保持 `#060608`，保证 Tab 栏与正文区对比度稳定。
4. **日间模式**：光晕 alpha 减半（.10–.16），落在 `#F4F5F7` 上呈"薄雾"而非辉光。
5. **无封面书**：深灰三段渐变（`#2A2A33 → #1C1C24 → #141419`）+ 竖排书名 + 格式小字（TXT · 无封面），光晕用中性灰紫，不使用极光色。
6. **物理封面不反转**：日夜模式切换时封面图本身不变，只变光晕强度与界面令牌。

## 七、关键交互契约（沿用 v15，不可回退）

- **读听定位分离**：每本书的阅读位置与听书位置独立存储、独立展示（详情页双轨："读到 · 第十章 38%" / "听到 · 第三章 12%"）；主按钮措辞遵循实际记录，"继续阅读"与"开始/继续听书"不混用。
- **播放键与展开键不互替**：迷你播放器与阅读页听条上，播放/暂停键与展开（⤢）键是两个独立按钮，均 ≥ 44pt，各自有完整无障碍标签；点胶囊其余区域才进入全屏播放器。
- **滑杆松手提交**：句子滑杆拖动过程只预览、松手才跳转；暂停不自动恢复；换书 / 跨章不应用旧拖动目标。进度以"第 N / M 句"呈现，不伪装成音频时间。
- **剩余时间标「约」**：一切由语速推算的时间（"本章剩余约 18 分钟"）必须带「约」；成功反馈不弹确认框。
- **44pt 触控与 Dynamic Type**：图标键触控区 ≥ 44pt；关键文字支持 Dynamic Type，辅助功能大字号下书库强制列表视图、首页恢复纵向双文字按钮；长句、小屏、最大字号需回归。
- **对比度 ≥ 4.5:1**：含渐变按钮文字与玻璃上的次级文字；玻璃底下的页面亮度变化不得把文字对比度拉低到阈值以下（必要时控件加实色垫底）。
- **最大字号 / 矮窗口**：播放器仅固定播放与跳句，跟读区与工具键可滚动。
- **VoiceOver 与减少动态效果**：光晕与星野在"减少动态效果"下静止；封面取色光晕是纯装饰，对 VoiceOver 隐藏。
