应用图标候选

六个候选均与软件内 v21「瑞士网格」界面同源：苏黎世白、近黑墨、单一信号蓝 #0057FF、无渐变与装饰圆角。每张卡按 iOS 实际效果预览：大图带 22.37% 圆角遮罩，下方为 64 / 44 / 32px 小尺寸在浅色与深色桌面上的辨识度检查。全部为 1024×1024 无 alpha PNG。

A / OFFICIAL

翻页成声 · 白

v21 设计稿官方符号的浅底变体。白底在主屏幕最安静，蓝符号在白底下最锐利；书页化成声弧，读与听一个动作。

B / BOARD PRIMARY

翻页成声 · 蓝

设计板标注的 PRIMARY：信号蓝满版 + 白符号，饱和度最高、桌面跳脱感最强，是 v21 的主打方案。小尺寸下符号依然清楚。

C / DARK-READY

翻页成声 · 墨

炭黑底 + 亮蓝符号。若选 A 或 B 为主图标，此版可直接作为深色外观变体；单独使用也成立。

D / PLAYER MOTIF

刻度 · 白

取自 v21 听书页的句子刻度轨：6 根信号蓝「已播」高刻度 + 5 根灰「未播」矮刻度，一条正在进行的听书进度。最克制，但小尺寸下灰刻度会隐去。

E / PLAYER MOTIF

刻度 · 蓝

刻度母题的满版蓝变体：白色已播刻度 + 半透明未播刻度，像电平表。比 D 更响亮，仍完全是界面语言。

F / TYPOGRAPHIC

字标 · 听

瑞士海报排版：mono 眉题 + 粗墨线、超大无衬线「听」、信号蓝方块句号、「READ · LISTEN — NO.21」版号署名。延续 v16–v20 以「听」立骨的传统，但完全换成 v21 的骨架。
