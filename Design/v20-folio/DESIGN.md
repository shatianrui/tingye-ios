## 版式规则

- 报头：英文眉题（`TINGYE · 听页` / `NO.<当年第几天>`）→ 3pt 墨线 → 宋体大标题 → 1pt 墨线。
- 区块：2pt 墨线 + 粗体标题 + 可选陶土编号；列表用 `01 02 03` 陶土宋体编号与发丝线。
- 圆角：卡片 2、按钮 0。主按钮陶土块 + 炭黑字；次按钮 1.5pt 墨线框。
- 页签：顶部 2pt 墨线，`01/02/03` 编号 + 宋体「书 / 读 / 己」，选中为墨色加粗 + 陶土下划线。
- 读页：封面故事（大书名、全书百分比大数字、右侧书封）、编号目录、七日栏（陶土柱）。
- 听书：`NOW READING ALOUD` 眉题，当前句宋体大字 + 陶土引号 + 陶土竖条浅底；陶土方块播放键；工具栏 Ⅰ 目录 / Ⅱ 语速 / Ⅲ 声音 / Ⅳ 定时。
- 占位书封：直角，顶部墨线、宋体书名、底部陶土条；真实书封优先。
- 阅读纸色：默认纸随象牙 / 炭黑，跟读色统一陶土橙；用户已保存的纸色与字体不重置。
