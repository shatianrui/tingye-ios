## 当前版本：播放器修正（1.17.0 · 98，2026-10-18）

在 1.17.0（97）「刊」设计上的修正版，不改视觉与数据格式。

- **播放器长句**：当前句较长时会被底部控制区挡住。现在换句、换章时自动把当前句滚进视野——放得下时停在上方约四分之一处，比可见区还高的长句贴顶从句首显示。

## 设计

- 2026-10-13 起采用 v7「一页」设计（设计稿 `Design/v7-yiye/index.html`，上一版 Swift 源码备份在 `build/v6-swift-backup/`）。三条原则：**原生为骨**（系统 `TabView`、大标题导航、`.toolbar`、分档 sheet、`Form`；iOS 26 起自动液态玻璃，悬浮控件用 `glassSurface()`，旧系统退回材质模糊）、**读听一体**（听书是阅读页的一种状态，不是另一个页面）、**一色到底**（靛蓝 `#2F4C7D` / 深色 `#9DB4E0` 是唯一强调色：主按钮、选中、进度、朗读高亮；取消金箔与朱砂分工）。底色 `#F5F4F0` / 暖黑 `#0F0F0E`，内容卡 22pt 圆角无阴影，按钮全部胶囊形；界面一律系统字体，思源宋体只给书名与正文。封面色板保持不变，并用作今日继续卡、详情头图和展开播放器的渐变底（自带封面图时取平均色）。
- 页签：**今日**（继续卡 · 今日时长 · 今日一句 · 待阅读 · 最近添加）/ **书架**（搜索 · 状态与分类筛选 · 网格 / 列表 · 排序 · 导入）/ **我**（阅读时长图表 · 阅读与听书 · 数据 · 关于）。原「发现」拆入今日与书架：今日重读改为「今日一句」，每天从书架轮换一本并摘出一句，「从这句读」一次性定位到该句（`AppModel.readerJump`）。正在听的书挂在页签栏附件（iOS 26.1+ `tabViewBottomAccessory`），更早的系统在页签底部浮同形玻璃胶囊。
- 阅读页四种状态：沉浸 → 轻点中间显示玻璃顶栏（返回 · 章节名 · 书签 / 字样 / ⋯）与一条章节栏（目录 · 上一章 / 滑杆 / 下一章 · 夜间）加靛蓝「听」键 → 点「听」后底部常驻**听条**（播放 / 暂停 · 句序与朗读方式 · 上一句 / 下一句 · 语速 · 定时 · 展开），正文原地高亮跟读；手动翻到别处时浮出「回到朗读处」 → 轻点或上滑听条展开播放器。听条出现时正文底部让出 76pt（开始 / 结束听书时重新分页一次），高亮句不会被盖住；顶栏与章节栏显隐仍不改变正文尺寸。朗读高亮为行高靛蓝浅底 + 2pt 下划线。⋯ 菜单：原书图文、听书与声音、导出备份。
- 展开播放器：封面色深渐变底、白字白键；句子流（上一句 / 当前句 / 下一句）、章节滑杆、上一章 · 上一句 · 播放 · 下一句 · 下一章、语速胶囊，底部 AirPlay · 定时 · 声音 · 章节；右上「原文」从阅读页打开时收起，从迷你播放器打开时翻开这本书。
- 字样：半高 sheet 放字号、字体、七种纸色（宣纸跟随 App 外观在夜间变为暖黑）、翻页方式；行距、段距、边距、缩进、对齐、双页、原书图文、恢复默认收进「更多排版」。
- App 图标 v7「一页成声」：靛蓝底，左边一页书，右边的书页化成四道声波（`Design/render-app-icon-v7.swift` 生成浅色 / 深色 / 着色三套）。灵动岛与锁屏实时活动调色板同步为靛蓝。
- iCloud 进度同步：默认开启，用 iCloud 键值存储在同一 Apple 账号的设备间同步每本书的章节与句序号（不含书籍内容），按规范化的书名、作者与格式匹配同一本书（忽略空白、大小写与全半角，不含章数；应用前校验章节不越界；同时读写 build 61 及更早版本使用的含章数旧键，兼容旧版本设备），较新的时间戳优先。时间戳为混合逻辑时钟：本机写入时间取 max(当前时间, 已见远端最大时间 + 1)，避免设备时钟偏差让新操作被判为旧。位置未变时不写入也不推送（关闭阅读页不会以旧位置覆盖其他设备的新进度）；正在阅读或朗读中的书不会被打断，关闭阅读页或朗读暂停 / 结束后再合并被搁置的远端进度；可在「iCloud 备份与同步」中关闭。该页显示同步状态：已开启 / 已关闭 / 等待 iCloud（未检测到 iCloud 账号）/ 同步出错，以及本次启动的「最近本机提交」与「最近收到更新」（含已应用和因正在阅读而保留本机位置的数量）。「本机提交」只表示已交给系统，系统不会告知上传完成或另一台设备何时收到，到达时间不作保证。合并写入本机书架失败会显示为同步错误，不再静默忽略。
- 设置：「我」页分「阅读与听书」「数据」「关于」三组，系统设置式彩色小图标；iCloud 页标题改为「iCloud 备份与同步」。

## 参照 PureLibro 的增强（2026-10-14，1.14.0（85））

以 PureLibro 3.3.27（App Store 截图与功能说明）为参照，在 v7「一页」视觉基础上补齐书库管理、书源、统计、阅读与听书功能。没有复制它的图标、名称或图片素材。

- **页签**：书库 · 书源 · 统计 · 我的。原「今日」页拆入书库（继续阅读一行）与统计（今日一句、阅读目标）。
- **书库**：累计阅读时长；「书籍 / 漫画」切换；多级分组（路径以「/」分隔，分组以四格封面文件夹显示，可重命名、删除分组而保留书籍）；编辑多选（移动到分组、隐藏 / 取消隐藏、移除）；筛选菜单（状态、排序、网格 / 列表、隐藏模式）；分类胶囊。
- **隐私**：隐藏书籍只在用面容 ID / 触控 ID / 设备密码验证后显示，退出 App 自动重新隐藏；「我的 → 应用锁」开启后启动和从后台返回都要验证（`Library.swift` 的 `PrivacyLock` / `AppLockGate`）。
- **统计**：日 / 周 / 月 / 年 / 总，可前后翻；在读、读完、阅读次数、笔记数；每日阅读目标仪表盘（默认 30 分钟，可改）；柱状图；逐次阅读时段（同一本书 3 分钟内的连续活动合并为一条）；按书排行。逐次记录保存在本机 `reading.sessions.<owner>`，最多 3000 条，统计导出 JSON 一并包含。
- **书源**：WiFi 传书（Network.framework 本机 HTTP 服务，只在页面打开期间运行，8080 端口被占用时自动换端口，屏幕常亮，单文件 100 MB）；WebDAV（PROPFIND 浏览、下载导入）；OPDS（导航、分页、OpenSearch 搜索、优先下载 EPUB）；SMB / NAS 通过系统「文件」App 的「连接服务器」接入。远程书库密码存钥匙串；ATS 只放行局域网 http（`NSAllowsLocalNetworking`）；Mac 版增加 `com.apple.security.network.server`。
- **新格式**：MOBI / AZW / AZW3（自研 PalmDB 解析，支持 PalmDOC 与 HUFF/CDIC 压缩、尾部附加数据、EXTH 作者 / 书名 / 封面，按分页标记拆章；DRM 书籍明确拒绝）；CBZ / 图片 ZIP 漫画（每张图一页，按自然顺序排序）。RAR / CBR 因解压库许可证限制未支持。
- **漫画模式**：左→右、右→左（日漫）、上下条漫；降采样解码；双击放大、捏合缩放；页码滑杆；进度按页保存并参与 iCloud 同步与统计。
- **划线与笔记**：长按正文选中一句（可向前 / 向后扩展），面板提供 5 种颜色、浅底 / 直线 / 波浪线三种样式、听、笔记、复制、分享、删除；划线以「章 + 句」坐标保存在书库目录（`ShelfEntry.highlights`，可选字段，随 iCloud 快照备份）；目录新增「笔记」页签，详情页「划线与笔记」，「我的 → 书摘」按书汇总、可搜索、可导出 Markdown。
- **排版**：字间距；简繁转换（只改显示，长度不变时才转换，保证进度与划线坐标）；导入 TTF / OTF / TTC 字体（「我的字体」）；自动翻页（10–60 秒，打开工具栏或划线时暂停）。
- **听书**：新增 Microsoft Azure（Speech Key + 区域，内置 24 个常用中文神经网络音色）与 ElevenLabs（带逐字时间戳，可在线拉取账号音色）；**分角色配音（Beta）**：根据引号与「他 / 她 / 公子 / 姑娘……说道」判断对话说话人性别，男女角色换用不同音色，判断不出来时用旁白声音；系统声音与各云服务均可用。
- **兼容性**：新增字段全部可选，旧书库目录与旧 iCloud 快照照常读取；跨端 `BackupPacket` 协议不变。
- **发布**：1.14.0（85）于 2026-10-14 以 Apple Distribution 签名归档，iOS 与 Mac Catalyst 均已上传 App Store Connect，进入 TestFlight 处理队列。
- **验证**：iPhone 17e / iOS 27 模拟器 54 项单元测试通过（新增 MOBI 解析 / DRM 拒绝 / 尾部数据、CBZ 导入、简繁长度、分角色判断、OPDS 解析、分组与旧目录解码、划线坐标共 10 项）；WiFi 传书用 curl 实测上传 TXT、4 MB 大文件与 CBZ 成功、图片被拒绝；模拟器实际操作长按划线（浅底、波浪线）、漫画翻页与工具栏。WebDAV / OPDS 未连真实服务器实测；Azure / ElevenLabs 未用真实密钥实测；面容 ID 未在真机实测。

## 已实现

- 本机书架、标题/作者搜索、导入、JSON 备份导出与分享。删除书籍提供「仅删除本机」与「删除本机和 iCloud」：后者从全部账号目录的 iCloud 备份快照中移除该书（含其他书的快照改写回原文件、只含该书的快照删除，未下载的快照先请求下载），并清除该书进度同步的新旧键；iCloud 侧失败时本机副本保留，可重试。
- 已读进度按各章句子数量加权；旧书架后台补齐本机索引，不改变跨端 v2 协议。
- 「我 → iCloud 备份与同步」支持手动保存、还原当前书架的本机书籍、资源、进度与书签。每次保存独立快照；还原前显示时间和数量，只替换对应书籍，其余保留。当前账号目录没有快照时会自动扫描 `Backups/` 下全部账号目录取最新一份（新设备以 guest 运行、旧备份在登录账号目录下的情形），确认页会注明备份来自旧账号目录，还原后归入当前书架。
- 手动备份 / 还原显示阶段清单：备份为「连接 iCloud Drive → 读取本机书籍 → 写入 iCloud Drive」，还原为「连接 → 查找最新备份 → 等待 iCloud 下载 → 读取备份 → 校验备份 → 确认 → 还原书籍 → 替换本机书库 → 重新载入书架」。读取本机书籍、校验、还原书籍按实际已处理 / 总本数显示进度条；连接、下载、写入等无法预估的步骤只显示转圈，不显示百分比。读取阶段可取消，失败或取消后可重试（还原重试会重新读取并再次确认）。状态保存在 App 模型中，离开再进入页面仍可看到；切到后台时向系统请求宽限时间。备份写入后自动查询系统报告的上传状态（等待上传 / 正在上传 / iCloud 已确认上传 / 上传出错），约 90 秒后停止自动查询，可手动刷新。

- 原生 CoreText 分页、连续滚动、目录、全文搜索、书签、字号/行距/字体/纸色、PDFKit 原版 PDF。
- 系统离线朗读实时逐词高亮、GLM/MiniMax 云朗读、MiniMax 时间戳映射、无时间戳句级提示、自动跟随翻页、当前词调速续读、章节跳转、变速、睡眠定时、锁屏播放控制。云语音内存缓存、下一句预合成和有界网络 / 限流重试。

## 当前边界

- EPUB/HTML 可切换原书图文（本机 WKWebView 渲染，禁用出版物脚本与外部网络），支持包内正文图片、表格和关联 CSS；Markdown 导入时由正文同源生成原书图文，两种模式的句级高亮与进度一致。原书图文为横向分页：点按左 / 右侧或滑动翻页（含链接区域），点按中间显示 / 隐藏工具栏，首页 / 末页越界翻章；朗读跟随时当前句进入另一页即自动翻页，支持当前朗读句高亮与跨标签 / 重复句定位。旧纯文本副本需修复后才具备原书图文。机器还原译文 EPUB 中的「原文链接」回链残留（`restored-source-link`）在导入时剔除，原书图文渲染时也一并隐藏。复杂 CSS 导入、固定版式、跨章节锚点及逐字高亮尚未完整等价。PDF 保留原版式。
- DOCX 和 Markdown 以阅读文字为主，不完整复刻复杂表格和出版物排版。带 DRM 的书籍不支持；扫描 PDF 可查看，但没有 OCR 朗读。
- 跨端位置继续使用原客户端的“章节 + 句子序号”。翻页定位精确到句子，尚未保存句内字符位置。
- 新导入文件上限 100 MB，解压资源上限 130 MB，正文上限 400 万 UTF-16 字符 / 3000 章。PDF 上限 22 MB。
- 直连 GLM / MiniMax 的付费合成尚未用真实密钥实测。
- 本机导入目录位于 Documents/TingyeNative/<owner>/Books，owner 为 `guest` 或旧版登录用户的账号 ID。

App 目标已开启 Mac Catalyst，macOS 使用 `Tingye/Tingye-macOS.entitlements`（App Sandbox、网络、用户选择文件、iCloud、钥匙串）。正式签名需先在开发者账号中注册这台 Mac。未注册时可生成本机 ad-hoc 签名版（不含 iCloud / 钥匙串分组权限，iCloud 备份不可用）：

```sh
cat > build/mac-local.xcconfig <<EOF
CODE_SIGN_STYLE = Manual
CODE_SIGN_IDENTITY = -
DEVELOPMENT_TEAM =
CODE_SIGN_ENTITLEMENTS[sdk=macosx*] = $PWD/build/Tingye-macOS-local.entitlements
EOF
xcodebuild -project Tingye.xcodeproj -scheme Tingye -configuration Release \
  -destination 'generic/platform=macOS,variant=Mac Catalyst' \
  -archivePath build/Tingye-mac.xcarchive -xcconfig build/mac-local.xcconfig archive
```

`create-project.rb` 可用 xcodeproj Ruby gem 重建工程；正常开发无需运行。
