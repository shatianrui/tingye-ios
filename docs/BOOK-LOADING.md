# 书籍加载与显示优化

## 本轮改动

- EPUB 3 读取 nav、EPUB 2 回退到 NCX，将真实目录名称和层级映射到正文文档；显示层级缩进，始终沿用 spine 的阅读顺序。混合 XML 文字按原顺序保留，避免嵌套 span 的标题错序。
- 保留头部 style 样式，将样式表中的图片/字体路径按样式表目录解析；行内样式按章节目录解析。支持普通 img、SVG image href/xlink:href、SVG 图片和书内字体；同章内嵌 data 图片可进入插图列表。资源 URL 转换不会替换正文中的同名字符串。
- 资源路径先解码再校验，兼容中文、空格、父目录与片段链接，保持资源只在出版物内部解析。
- 封面和插图预览通过 ImageIO 按目标像素数生成缩略图，避免先创建全尺寸位图。插图有加载状态和失败说明；纯插图章提供直接打开原书图文的按钮。
- WebKit 资源使用串行后台解码队列和按字节计费的 NSCache（目标 24 MiB、64 项；缓存由系统管理，非严格进程内存上限）。超过目标大小的单张图片只交付、不缓存；已停止请求不会再回调。
- 后台索引复用已有书籍对象和句数，避免新书导入后再读整本 JSON、再逐章分句。打开任务取消后不把过期结果写入缓存。
- 大 TXT 分章不再反复统计剩余长字符串长度；HTML 样式标记用增量 UTF-16 坐标，保留中文、emoji 与已有标注坐标。目录使用章节索引迭代，减少每次刷新创建中间数组。

## 兼容范围

既有书库和备份协议不变。阅读/听书位置、正文纸色和字体偏好继续使用原值。已导入书籍可受益于索引与显示优化；新的 EPUB 目录和资源解析需要从原始文件重新导入，旧书籍文件不自动重写。

目录仍以 spine 文档为章节单位。同一 XHTML 内多个锚点目录项本轮只取首个有效名称，不会拆章或重建历史阅读位置。复杂 CSS @import、固定版式及混淆/加密字体未新增支持。独立 HTML 的外部相邻文件未在本轮打包。原书图文模式保留图文结构，文字模式继续面向纯文本阅读。

## 验证事实

本环境为 Linux，未安装 Xcode、iOS SDK 或 Swift 编译器。

已完成：

- 6 个修改涉及的 Swift 文件通过 tree-sitter Swift 语法解析，无错误或缺失节点。此检查不能代替 Swift 类型检查。
- 两份新增合成 EPUB 的 ZIP 完整性、mimetype 条目和全部 XML/OPF/XHTML/NCX/SVG 结构检查通过。
- `git diff --check` 通过。

新增 `BookLoadingTests` 共 8 个 XCTest 用例，涵盖 nav/NCX、spine 顺序、资源与备份往返、路径解析、SVG/样式替换、emoji 标记、长 TXT 和缩略图尺寸。两份合成书籍由 `scripts/make-loading-fixtures.py` 可重复生成；字体条目是导入路径测试数据，不是真实字体，不用于渲染验收。

这些 XCTest 尚未执行；已加入手动 Unsigned iOS 工作流。需要在 Mac 上完成编译与测试，并用实际大书检查首屏时间、峰值内存、目录跳转、图文翻页及夜间排版。没有声称已获得性能提升百分比或真机验收结果。
