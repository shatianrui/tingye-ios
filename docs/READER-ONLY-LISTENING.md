# 删除独立「正在听」页面

用户提供截图后确认：需要删除的是带封面、独立跟读卡、大播放键及「回到原文」按钮的完整播放器页。

实现：移除 PlayerView 页面及其专属句子/章节进度组件，移除根级播放器 sheet、正文的播放器 sheet 与所有展开播放器的跳转。首页、书库和迷你播放条改为进入正文，显式定位到音频当前章节/句子并开启高亮跟随；普通「阅读」仍恢复独立阅读位置。打开正文听书不擅自恢复暂停的音频。

正文听条保留上一句、播放/暂停、下一句和朗读设置菜单；声音、中国区 GLM/MiniMax、语速和定时设置仍可使用。阅读目录仍为正文目录。声音与朗读的配置页保留，不再经过独立播放器。

替换原有播放器 UI 回归，增加模型层的正文路由/暂停/跳章验证，并在定向 CI 中覆盖正文跳句、迷你条回正文、最大字号控件和中国区声音设置。实际结果以本次修复标签的 GitHub Actions 为准。
