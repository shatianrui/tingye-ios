## 首页与书库

首页「此刻」始终以「开始阅读 / 继续阅读」为主操作，优先展示最近实际阅读的可见本地书籍。最近听过另一本书或仍在播放，不会把主卡改成听书，也不会把阅读续读位置换成听书位置。今日阅读时长与连续天数取阅读会话，听书记录不计入这两个首页指标。

书库点书仍直接进入阅读；搜索、分组、筛选、整理与漫画入口保留。最近排序使用阅读时间，列表显示阅读百分比、所在章节或漫画页码以及最近阅读日期，网格补充最近阅读日期。听书留在书籍菜单中。开启「启动续读」后只续读最近实际阅读的书，沿用不自动打开漫画的行为。

导航继续使用「此刻 / 书库 / 我的」。迷你播放器采用中性样式和更紧凑的间距，保留展开、暂停 / 继续与至少 44pt 的触控范围；已暂停会话仍可从这里恢复。

## 正文工具与辅助听书

正文固定工具为 **目录 / 排版 / 摘记 / 更多**，不会随播放状态改变顺序。「摘记」直接进入本书划线与笔记；目录、书签、原书图文、PDF 与漫画的既有阅读能力保留。

「更多」中的「辅助听书」提供「从当前阅读位置听」。选择后从眼前正文位置朗读，并留在阅读页，不自动弹出完整播放器。当前书籍开始朗读后，正文显示轻量播放控制；只有主动选择「听书设置与控制」或展开播放器，才进入完整听书页。「跟随朗读位置」和「结束辅助听书」也在该分组中。

普通翻页、跳章、目录或搜索定位只改变阅读位置。听书跳句和后台朗读更新另一份位置。读者主动开启跟随朗读时，正文会移动到朗读处，阅读位置也会保存为当前实际可见的正文位置；这与后台播放覆盖阅读记录不同。

## 统一计时与统计

全应用使用一个 **5 秒计时时钟**，每次只将这段时间归入一类活动：

- App 在前台且正文阅读页可见时计为阅读，包括一边听一边读的情况，不再同时增加听书时长。
- 正文不在眼前（包括打开完整听书页或 App 退到后台），只有音频仍在播放且不处于缓冲状态时才计为听书。
- 正文不可见且音频已暂停、停止或正在缓冲时，不累计这段使用时长。

首页「今日阅读」与连续阅读天数只取阅读会话，是纯阅读数字，不混入仅听音频的时间。「我的」本月概览与阅读足迹仍可查看读听合计及分别统计；每个计时周期只累计一次，边听边读不会重复计入总时长。

## 读听位置与兼容

位置坐标仍为「章 + 句子序号」，没有改成字符偏移。

| 字段 | 职责 |
| --- | --- |
| `ShelfEntry.progress` | 阅读位置，供正文恢复、书库进度和自动 iCloud 续读使用 |
| `ShelfEntry.listeningProgress` | 可选的独立听书位置，播放与跳句回调只更新这份记录 |
| `ShelfEntry.lastReadAt` | 可选的最近主动翻开阅读时间；与阅读位置更新时间共同决定最近阅读顺序 |

新增字段均为可选，旧目录和旧手动快照缺少它们时仍可解码。旧版只有一份共享位置，无法从这个单点重建此前独立的阅读与听书历史；升级保留原位置，不猜测或清空旧进度。尚无独立听书位置时，首次听书回退到保留的阅读位置；此后两份位置分别更新。显式选择「从当前阅读位置听」则以当前正文位置作为这次听书的起点。

## 保存、同步与备份

| 方式 | 阅读位置 | 听书位置 |
| --- | --- | --- |
| 本机书库目录 | 保存 | 独立保存 |
| iCloud 键值存储自动同步 | 同步 | 不同步 |
| iCloud Drive 手动快照 | 备份并恢复 | 通过可选字段备份并恢复 |
| 跨端单书 `BackupPacket v2` | 保持既有协议 | 不加入该协议 |

自动 iCloud 只同步阅读位置，不自动传输书籍。两台设备仍需各自持有同一本书，实际到达时间由 iCloud 决定。听书位置平时留在本机，需要迁移时可随手动快照带出。

手动快照中的 `packet.progress` 保存阅读位置，外层可选的 `listeningProgress` 和 `lastReadAt` 保存听书位置与最近阅读时间。旧快照没有这些字段时沿用上述回退规则；恢复仍需校验与确认，只替换快照中的对应书籍，其余书籍保留。

## 书内搜索

「更多 → 书内搜索」可查找章节与全文。同一章内的多次正文命中分别列出，每处包含上下文，并定位到对应的阅读句。**上限为全书前 200 处结果，不是每章 200 处**；达到上限时界面提示输入更完整的词句缩小范围。搜索在后台执行，正文匹配忽略大小写；某章正文未命中但章名命中时，结果定位到该章开头。
