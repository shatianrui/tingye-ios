听页 1.24.0 的无签名改版，本次修复本地文件点选后未立即导入的交互。

- 普通文件导入改为单本点选即导入；需要多本时使用「批量选择文件」并确认选择。
- 文件选择器复制文档到本机后再读取，选择结果直接交给导入任务，取消选择不创建任务。

- 首页、书库与底部导航更新，阅读纸色与字体偏好继续沿用。
- EPUB nav / NCX 目录标题与层级、SVG 插图及样式资源解析改进。
- 封面与插图按尺寸解码，减少重复索引与资源解码。
- 构建不需要原开发者证书；此版本关闭依赖原团队权限的 iCloud 功能，本地阅读、听书与导出保留。

附件 `Tingye-unsigned.ipa` 为未签名产物，普通 iPhone 安装前需用自己的签名工具重新签名。`Tingye-unsigned.ipa.sha256` 用于核对下载完整性。

发布工作流先运行无签名能力隔离和书籍加载与本地文件导入共 15 项定向回归（含系统选择器点选导入 UI 测试），再构建、检查并上传 IPA；不代表原仓库全部测试或真机安装已验收。新目录与资源解析适用于重新导入的原始 EPUB，已有书库文件不自动重写。
