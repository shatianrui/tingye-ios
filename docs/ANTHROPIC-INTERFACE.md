# 听页 · 新纸面界面（1.26.0 / 143）

本次是在正确 Readium 基线上重新设计的应用 UI，受 Anthropic 的暖纸与编辑式留白启发，非官方关联。没有移植或重命名 v30 的设计规范、图标、页面或资源，也没有生成营销资产。

**实施状态：implemented-static-only。Linux 静态检查不等于 Xcode 编译、设备运行、截图、VoiceOver 或视觉验收。** 完整范围逐项见 [147 项覆盖表](ANTHROPIC-REDESIGN-COVERAGE.md)，导入见[回归说明](LOCAL-IMPORT-REGRESSION.md)。

## 可复用组件和层级

组件实现在现有 `Tingye/Theme.swift`，避免新增 Swift 文件漏进 target：

| 组件 | 实际职责/接入 |
| --- | --- |
| EditorialIntro | 页面滚动内容中的眉题、宋体标题、说明与细线；不是固定在小屏上挤压内容的巨型页头。书房、搜索、详情、各设置、来源、目录、专注和读完使用 |
| EditorialRow | 图标、主标题、说明、当前值、导航指示分层；辅助字号将当前值移到主文下方。设置、详情操作、来源、SMB/WebDAV 文件、存储分项使用 |
| PaperPanel | 纸面、边界、内边距；提高对比模式加粗边界。续读、网格、迷你播放器、状态、备份/同步使用 |
| EditorialNotice | 信息、处理中、完成、失败四类语义；符号与标题一起表达状态，长说明可选择。搜索、书签、字体、朗读、连接、备份状态使用 |
| editorialList | 原生 List/Form 的行高、分组间距和表面；所有深层设置、浏览和目录容器统一接入 |
| SectionTitle/PageMasthead/SettingsRow | 改造现有共享组件，保留调用 API；标题可缩放，说明/值可换行，栏目线条建立阅读节奏 |
| 主/次按钮 | 主操作墨底纸字，次操作纸底描边；状态色用于意义和选中，不用大面积强调色填满页面 |

应用 UI 日间：纸 `#F7F4ED`、面 `#FFFDF8`、次面 `#EEE9DF`、墨 `#292724`、次文 `#625B52`、强调 `#98432E`。夜间：纸 `#201F1C`、面 `#292723`、主文 `#F1EADF`、强调 `#E9A18A`。提高对比的边界有独立色值与粗细。普通文字采用 SwiftUI 原生动态文字角色；自定义字号通过已有 scaledFont/ScaledMetric 接入。宋体保留真实已授权字体，不合成不存在的粗体。

## 实际模块变化

- 书房/书库：滚动的编辑式页首、明确“正在读”的续读面板；网格有封面与详情的边界，列表有纸面书目行；筛选、排序、显示用独立图文触发器，整理与搜索不混淆。保留真实封面、所有分组与选择/删除/隐藏语义。
- 详情/管理：封面与元数据随辅助字号适配，说明与目录预览分层；目录、摘记、书签、分组、简介、修书、导出与删除均保持独立入口；分组选择器和章节管理使用新列表骨架。
- 来源/电脑传书：本机单选和批量有明确入口；WebDAV/OPDS/SMB 的连接、文件信息、当前值与恢复状态分层。实际内嵌 WiFi 浏览器网页加入步骤与队列的编辑式布局，支持日夜、高对比、窄屏、减弱动态效果和现有 aria-live；未改认证或上传协议。
- 阅读：EPUB 与原生 TXT/PDF 都重做自有标题/工具层，保持目录/排版/摘记/更多及所有现有动作。EPUB 目录支持原书层级/回退、书签空态和未定位摘记说明；全书搜索有等待态。保留原生阅读器专注/读完/自动翻页等入口；不把这些冒充为 EPUB 新增功能。
- 选段/摘记：标注、笔记、引用面板保留原文色彩语义和三类工具；笔记编辑提供完整可滚动引用，辅助字号下列表操作改为纵向。复制/分享/从此处听、扩选、颜色、三种样式、删除和原文跳转全部保留。
- 漫画：三种方向、缩放和页码数据不变；工具区可滚动，页面目录和仅书签状态新布局，缺失/损坏图片从无限 spinner 改为明确反馈与修书指引。
- 听书：页首、声音摘要、当前句区域、工具格、错误恢复和迷你条统一重排；大字号仍保留核心播放。音色、节奏、分角色、六类服务配置/模型/自定义声音、试听/保存和输出路由保持。
- 我的/统计：月度概览使用纸面层级，阅读足迹有明确的时间范围与内容页首；统计口径不变。日历保证日期目标最小宽度（窄屏可横滚），月汇总可换行；空日说明明确。专注、完成小结、读完感、下一本与分享摘句视图沿用同一排版。
- 设置/数据：全部 13 个目的地和深入页面使用新表单层级。原 EPUB 与派生缓存有不同说明；备份保存/恢复/上传/同步状态分别呈现，保留真实阶段与系统到达限制。隐私锁屏的新说明与验证状态不暴露书房内容给 VoiceOver。

## 内容和能力的保护边界

`ReaderPaper`、`ReaderPreferences` 的值、字体映射与默认值原字节保持；EPUB 内容 CSS/HTML、Locator/迁移、spine/link、简繁显示桥、原包/缓存 pin、数据模型、持久化、读听分离和全部依赖保持。原生文字图文分页/滚动算法及 PDF 表现层也原字节保持。UI 颜色通过独立 Theme 实现，不注入出版物 DOM，不改变原 PDF 页面或漫画图像。

Readium 17 个源码全部存在；16 个引擎/桥接文件字节不变，只有 ReadiumReaderView 自有 UI 改动。原 OriginalBookView 定义和旧测试兼容保留，生产 EPUB 路由仍是 Readium。没有重新引入旧 WebView 或 tab 根结构。

系统选择器、分享、权限、确认对话框维持原生所有权；改造应用自己的触发器、布局、说明与反馈，不假装替换系统 UI。VoiceOver 焦点在真实 modal 关闭后的行为、最大字号/横屏/分屏和所有 renderer 上的视觉效果仍需 iOS 走查。
