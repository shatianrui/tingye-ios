# 听页 · 纸页与松绿

## 设计方向

暖纸画布、松绿强调色、宋体大标题。界面从原钴蓝卡片转为安静的私人书房：内容优先，操作集中，阅读与听书入口保持独立。

## 实现范围

- 此刻：首页增加品牌眉题与宋体标题；续读卡采用独立白纸表面、细描边、大封面和清晰主按钮；阅读目标使用进度环，保留真实阅读分钟与连续天数。
- 书库：统一宋体标题与藏书眉题；搜索、分组、排序、漫画、整理与导入仍沿用现有操作；添加按钮改用统一圆角。
- 我的：统一宋体标题，统计卡片与书摘通过语义主题采用新配色。
- 导航：选中项增加柔和松绿底与圆角，仍保留 VoiceOver 选中状态及原测试标识。
- 听书与设置等复用 Theme 的界面同步换色；未逐个重排所有二级面板。
- 阅读正文继续使用用户原有的纸色与字体偏好。辅助功能字号下，首页封面及目标模块继续采用纵向布局。

## 本次验证记录

在 Linux 完成差异空白检查、Bash 语法检查、Python 语法检查。

按现有 `testFocusTextContrastInBothAppearances` 的 15 组语义配对，在 Python 中核算两种外观共 30 组，对比度全部 >= 4.5:1，最低 4.88:1。这是令牌数值检查，不代表实际屏幕走查。

以临时测试包验证打包校验器：正常结构通过，缺少可执行文件、包含 embedded.mobileprovision、嵌套框架签名目录三类异常均被拒绝；测试包不是实际应用。

打包脚本在缺少 Xcode 时明确退出，未生成 IPA。新增 unsigned XCTest 验证不查询 Apple 账号、不启动云同步并拒绝云备份连接；该用例尚未在 Xcode 执行，手动 Actions 工作流会先运行此用例再构建 IPA。
