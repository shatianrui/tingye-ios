# 听页 1.24.0（121）实现与验收

2026-10-23，本轮图标与 SwiftUI 界面重设计已实现，原书图文阅读同步更新。最终一次完整回归 **100 项核心 + 20 项 UI，共 120 项全部通过**；iOS 与 Mac Catalyst 的 Release 归档及包检查通过。实际上传、Apple 处理及 TestFlight 可安装状态见[发布历史](RELEASE_HISTORY.md)，归档检查本身不代表可安装。

## 设计与实现

[当前 Figma 设计](https://www.figma.com/design/dYtodq4gYGkOJw1EPODDMY?node-id=16-22)包含 43 个界面与状态，[主要流程原型](https://www.figma.com/proto/dYtodq4gYGkOJw1EPODDMY?node-id=17-1342&starting-point-node-id=17%3A1342)包含 16 屏、64 条连接。设计中的书名、阅读记录等为示例内容。

- 品牌采用暖白、钴蓝与暖纸，图标为展开书页和三道声波；iOS 提供日间、深色、着色三种图标。
- 导航改为「此刻 / 书库 / 我的」。首页续读、书库搜索整理、传书、播放器、阅读足迹、设置与相关面板统一换新。
- 听书保留句子进度、播放状态、语速、声音、定时和回到原文；阅读翻章与声音定位保持分离。
- 原书图文、PDF、漫画的阅读工具同步更新。WKWebView 保留出版物图片与表格，排版、目录、书签、划线及笔记使用统一样式。
- 阅读工具参与实际布局，CoreText 与 WebKit 按正文剩余视口分页。工具开关或视口尺寸变化后保持当前阅读句，正文不会被工具层遮住。
- 界面自定义字体随 Dynamic Type 缩放一次；最大字号工具区可滚动。固定浅色纸在深色 App 中保留适合浅纸的强调色与跟读高亮。

现有书库、书摘、已保存的字体与纸色偏好继续保留；位置协议仍为章与句子序号，未改变 `BackupPacket v2`。

最终 iOS 模拟器测试使用临时书库、系统声音与关闭同步的 Debug 样本；未使用用户书库或付费语音接口。本机 `final-validation.log` 记录核心套件 100 项、UI 套件 20 项，均为 0 失败，最终结果为 `TEST SUCCEEDED`。
